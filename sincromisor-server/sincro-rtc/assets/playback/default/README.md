# 既定の再生確認用音声

## 用途と出典

RTCの返却音声・テロップ・口形同期を確認するための短い合成音声である。実ユーザーの録音は含まない。

- クレジット: **VOICEVOX:ずんだもん**（ノーマル、話者ID `3`）。
- 文章: 「こんにちは。音声と、口の動きを確認します。」本タスク用に作成した確認文。
- 生成日: 2026-10-12。管理下のVOICEVOX Engine `0.25.2`を使用。
- 生成処理: リポジトリの`VoiceSynthesizer.generate`でWAVと加工済みクエリ・モーラを生成し、FFmpeg `7.1`の`libopus`で48 kHzモノラル、64 kbit/sのOgg Opusに変換。
- 再生時間: `3.989333333333333`秒。前後の無音は各`0.1`秒、速度は`1`。`synthesis.json`は音声合成に実際に使ったクエリを保持する。

## 利用条件

音声の利用・再配布には、[VOICEVOXの利用規約](https://voicevox.hiroshiba.jp/term/)と
[ずんだもんの音源利用規約](https://zunko.jp/con_ongen_kiyaku.html)を適用する（2026-10-12確認）。
クレジット「VOICEVOX:ずんだもん」を利用者が確認できる場所へ記載し、各規約の禁止事項を守ること。
音声の利用を他者へ許諾するときも、同じ音声利用規約と、この条件を後の利用者へ引き継ぐ義務を課すこと。
リポジトリ本体のライセンスのみでこの音声を無条件に利用できるものではない。

アプリのplayback説明にも既定音声のクレジットを表示する。差し替え時は素材に対応するクレジットと利用条件へ更新する。

## ファイルと再生成

`voice.opus`と`synthesis.json`は一組として扱い、片方だけ差し替えない。
JSONの`query`は合成済み音声の記録用であり、RTCは`mora_queue`から時刻を検証する。
配置・生成・差し替え手順は[RTCサービスのREADME](../../../README.md#再生素材の準備と差し替え)を参照する。

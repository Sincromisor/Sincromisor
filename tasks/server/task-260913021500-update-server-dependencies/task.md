# サーバー依存ライブラリのメジャー更新を含む調査と更新

## 背景 / 目的

ユーザー要求に基づき、Python / Go のサーバー依存を公式配布元と照合し、メジャー更新を含めて現在の構成で採用可能な安定版へ更新する。

## 完了条件

- [x] 直接依存の最新安定版とメジャー更新を調査し、更新・保留理由を記録する。
- [x] 稼働対象の依存宣言とロックを更新し、依存解決と既存のサーバーテストで更新差分の回帰がないことを確認する。変更前にも再現する対象外の失敗は根拠を記録する。
- [x] 互換性上更新できない依存、実環境で未確認の事項を明示する。

## スコープと実装方針

ルートと `sincromisor-server/*/pyproject.toml`、`uv.lock`、`sincro-rtc/go.mod` / `go.sum` が対象。固定された MediaPipe も更新を検討する。旧 Nue 実装は Compose が受け付けず Python 要件も現行共通パッケージと不整合のため、調査対象とし、稼働系への再導入は行わない。推移依存はパッケージ管理ツールで再解決し、上流の制約を無理に上書きしない。

通信契約、保存形式、外部サービス構成を維持する。依存更新で公開挙動の変更が必要なら設計と提供側・利用側を同期する。

## 確認方法

`uv lock --check`、`uv sync --locked --group dev --group full`、サーバーの既存 pytest、`ty check` と主要モジュールの読み込みを確認する。Go は `go mod tidy`、`go test ./...`、`go vet ./...` で確認する。GPU モデル推論や本番接続は実行環境が利用できる場合のみ確認し、未実行なら明記する。変更 Markdown の整形、タスク整合性、コミット規約を確認する。

## 実装・確認結果

直接依存とメジャー更新を調査し、採用可能な最新版へ依存下限・ロックを更新した。Pythonは28テスト、型検査、YAMNet実モデル分類、Redisバイナリ往復、NeMo実モデル読込・GPU無音推論が成功。Goの静的検査・モジュール整合性は成功し、既存テストのICEタイムアウト1件は旧依存でも再現した。

[調査表・保留理由・確認結果](impl.md)に、全直接依存、旧Nue、xxhash4、既存Python要件不整合、未実行事項を記録した。[独立評価](eval.md)も参照する。既存問題はタスク管理規則に従って更新の回帰と区別し、今回の更新による未解決の失敗はない。

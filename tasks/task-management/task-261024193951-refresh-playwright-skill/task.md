# Playwright CLIスキルを公式最新版へ更新

## 背景 / 目的

ユーザーの依頼に基づき、`.agents/skills/playwright-cli/` を公式最新版と比較し、古い内容を更新する。

## 完了条件（受け入れ条件）

- [x] 公式のスキル本文と参照資料10ファイルを比較し、内容の更新を反映する。
- [x] プロジェクト固有の整形・運用を維持し、固定済みCLIとの対応差を記録する。
- [x] スキル形式、変更したMarkdownの整形、相対リンク、タスク整合性を確認する。

## 設計判断

`microsoft/playwright-cli` の `main`（`b1a5903c5b633b8c9f843ad7b629c2a78437040c`）は、既存スキルと整形を除き同じだった。移植元である `microsoft/playwright` の `main`（`b4695e3eb2e6736d1a7b1fd255c4e94f78553660`）には更新があるため、後者を採用する。公式資料の英語原文と、既存のMarkdown雛形の整形除外を保持する。

## スコープ境界

公式スキル、必要な利用ルール、タスク記録を更新する。CLI本体と依存パッケージのバージョンは変更しない。

## 実装方針

`SKILL.md` のスクロール操作、タブ分離、`--raw` の説明、`storage-state.md` のドメイン指定、`test-generation.md` の否定アサーション、`tracing.md` のブラウザー起動順序を同期する。その他の参照資料7ファイルは内容が一致する。

## テスト

スキル検証、変更ファイルのPrettier整形確認、スキル内の相対リンク確認、タスク整合性と索引検査を実行する。文書更新のためブラウザー起動は行わない。

## 確認結果

- `quick_validate.py` によるスキル検証と、変更したMarkdownのPrettier検査に合格した。
- スキル11ファイル内の文書への相対リンク17件が解決することを確認した。コード例の生成物パスは確認対象に含めない。
- `npm run tasks:index:check`、`npm run tasks:check`、`git diff --check` に合格した。

## ドキュメント同期の要否

利用ルールに採用した公式コミットと参照日を記録する。CLI 0.1.22の `tab-new`、`cookie-delete`、`mousewheel` のヘルプを確認した。新しい `--isolated-context` と `cookie-delete --domain` はヘルプに掲載されていないため、公式例を使う前に対応確認が必要であることを利用ルールに記載する。アプリの設計・通信契約への変更はない。

# Playwright CLI公式スキルの更新を反映

## 背景 / 目的

ユーザーが実行した `playwright-cli install --skills=agents` の反映状況を確認し、更新内容をコミットする。

## 完了条件（受け入れ条件）

- [x] 更新された公式スキルと参照資料をGit管理に含め、全相対リンクが解決する。
- [x] AGENTS.mdから専用プロファイルの利用ルールを参照でき、現行CLIのコマンドと整合する。

## 変更内容

公式スキルの更新を保持し、除外されていた参照資料10ファイルを追跡対象に加える。公式資料は上流の英語原文を保持し、整形のみ適用する。`test-generation.md` のMarkdown雛形はPrettierがリストの字下げを交互に変更するため、理由を記して当該コード例だけ整形対象外とする。利用ルールに公式スキル更新時の扱いを記載し、通信調査コマンドを `network` から `requests` へ更新する。インストーラーが追加した出力ディレクトリの除外指定は既存の指定と統合する。

## 確認結果

- CLI 0.1.22のヘルプで利用コマンドを確認した。
- スキル検証、Markdown整形、文書への相対リンク、タスク整合性と索引の検査に合格した。
- `.playwright/cli.config.json` は作成されていない。専用プロファイルは利用ルールの起動引数で指定する。
- 文書更新のためブラウザーの起動確認は行わない。

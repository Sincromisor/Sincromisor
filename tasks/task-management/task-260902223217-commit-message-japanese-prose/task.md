# コミットメッセージの日本語散文化を強制

<!-- tasks/AUTHORING-CHECKLIST.md と documents/rules/coding-md.md に従い、変更のリスクに必要な項目だけを日本語で具体化する。 -->

## 背景 / 目的

コミットメッセージに不要な改行、英語または英語交じりの説明、`Why:` / `What:` などの項目形式が繰り返されている。現在の規約、完了処理の生成内容、検査がこの形式を許可または生成しているため、過去の履歴を前例にして再発しない境界へ改める。

## 完了条件（受け入れ条件）

- [x] 正本が、日本語の件名と一段落の日本語散文を求め、英語の項目ラベルと不要な改行を禁止している。
- [x] タスク完了処理と索引更新が、規約に適合する日本語のコミットメッセージを生成する。
- [x] コミットメッセージ検査が、英語だけの件名・本文、英語の項目ラベル、不要な本文改行、文字列 `\n` を拒否する。
- [x] Gitのコミットメッセージ用フックから検査を実行でき、対象テストが合格する。

## 設計判断

新しい依存は追加せず、既存のNode検査とGit標準フックを使う。説明本文は一段落一行とし、構造上必要な件名・本文・フッター間の空行だけを許可する。

## スコープ境界

正本、コミット生成処理、検査、Gitフックを対象とする。過去のコミット履歴は書き換えない。

## 実装方針

`tasks/README.md` と `AGENTS.md` を同期し、`scripts/git/checkCommitMessage.mjs` をフックと履歴検査の共通実装にする。`tasks:close` と `tasks:reindex` の生成文も同じ規約へ合わせる。

## テスト

対象のBunテスト、完了処理のドライラン、タスク検査、Markdown検査、最終コミットのメッセージ検査を実行する。

## ドキュメント同期の要否

必要。タスク管理の正本 `tasks/README.md`、初動ガイド `AGENTS.md`、上流との差分を記録する `.agents/CUSTOMIZATIONS.md` を同期する。公開APIと通信契約には影響しない。

# Playwright CLIの利用ルールと専用プロファイルを統一

## 背景 / 目的

ユーザー要求に基づき、Playwright CLIの利用ルールを `documents/rules/` に集約し、AGENTS.mdから参照する。前の対話で指定した専用Chromeプロファイルの運用を含める。

## 完了条件（受け入れ条件）

- [x] 導入確認、専用プロファイルの起動と再利用、セッション操作、成果物、テストへの案内をルール文書にまとめる。
- [x] AGENTS.mdと既存スキルからルール文書へ辿れ、旧来の一時セッションの既定と矛盾しない。

## 変更内容

- `documents/rules/playwright-cli.md` を追加し、通常のChrome操作はリポジトリ外の専用プロファイルを使う。
- AGENTS.mdの参照先を変更し、生成対象外のplaywright-cliスキルを参照案内に絞る。
- アプリコード、通信契約、実際のChrome設定・プロファイルは変更しない。

## 確認結果

- インストール済みCLIのヘルプで起動オプションを確認した。
- 変更したMarkdownのPrettier検査、相対リンクの存在確認、スキル検証、タスク整合性・索引検査に合格した。
- 文書変更のためブラウザー起動による動作確認は行わない。

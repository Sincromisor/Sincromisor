# エージェント文書とスキルの参照範囲を整理

## 背景と目的

ユーザーが指定した [OpenAIの記事](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)（2026-09-13参照）を参考に、AGENTS.mdから読む文書・スキルの重複、適用範囲、停止条件を整理する。全体を読む指示、Markdown全体検査と対象限定方針の不一致、起票依頼を見送る指示、複数の実装方法があるだけで停止し得る条件が対象である。

## 完了条件

- [x] AGENTS.mdと設計索引が、作業別の参照先と読む理由を示す。
- [x] 起票・実行・ブラウザー操作のスキルが用途を区別し、詳細を必要時に参照できる。
- [x] 通常の判断・確認から完了まで進める範囲と、未決定事項を確認する条件が整合する。明示要求・コメント品質・契約・公開成果物の制約を維持する。
- [x] 生成元と生成済みスキル・エージェントが同期し、対象文書・リンク・タスク整合性を確認する。

## 変更範囲と判断

AGENTS.md、タスク用の指示と生成物、手書きのplaywright-cli入口、タスク管理の関連節、Markdown規約、設計索引・文書運用ガイド、独自変更記録を更新する。文書と指示の通常変更として、現在のワークツリーで実装する。

AGENTS.mdのコメント例・通信の説明は既存の専門文書への参照に集約する。コメント品質の必須範囲は変更しない。playwright-cliは既存の用途別参照資料とコマンドのヘルプを使い、入口のコマンド一覧を削る。生成ツール・モデル指定・アプリ実装・依存関係は変更しない。

## 確認方法

変更したMarkdownをPrettierで整形・検査する。`npm run gen:codex` と `npm run gen:codex:check` で原本と生成物の同期を確認し、skill-creatorの `quick_validate.py` で3スキルを検証する。変更文書の相対リンクと参照見出しを確認する。`npm run tasks:index:check` と `npm run tasks:check` でタスクを検査する。

指示の読み合わせでは、誤字修正、起票だけの依頼、既存タスク実装、公開通信契約変更、画面確認を想定し、適用する文書・停止条件・完了範囲を辿る。

## 確認結果

- 変更したMarkdownのPrettier検査と文書点検: PASS。
- `npm run gen:codex:check`: 生成物6件が最新であることを確認。
- `quick_validate.py`: new-task、run-task、playwright-cliの3件とも合格。
- 変更文書の相対リンク112件: ファイルと参照見出しの欠落なし。確認用スクリプトは `/tmp/check-agent-docs.py` に置いて実行した。
- 誤字修正は対象文書とMarkdown規約から着手し、全体読書・アプリ検査を要求しないことを読み合わせた。
- 起票のみの依頼はnew-taskでtask.md作成まで、既存タスク実装はrun-taskで対象確認・状態更新・コミットまで進むことを確認した。
- 公開通信契約変更は提供側・利用側・契約文書と高リスク経路へ進み、要求結果を左右する未決定事項がある場合だけ依存する作業を保留することを確認した。
- 画面確認はplaywright-cliの基本操作、テスト実行は既存のテスト手順へ進み、認証状態・画像の公開範囲が維持されることを確認した。
- Git管理外だったplaywright-cliの入口を管理対象に追加した。既存の管理済みテスト手順とCLIヘルプを参照し、管理外の追加資料を必要条件にしない。

`npm run tasks:index:check` と `npm run tasks:check` は状態更新後に合格し、371タスクの整合性を確認した。本番コードの変更はないためアプリのビルド・テスト、コメント点検は対象外。独立エージェントによる実行比較や実ブラウザー操作は行っておらず、モデルの挙動・性能改善を実証したものではない。

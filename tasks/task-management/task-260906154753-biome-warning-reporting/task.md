# Biomeの助言的な警告の記録方針を明確にする

## 背景 / 目的

ユーザーの要望に基づき、認知的複雑度などの助言的な警告を、実装タスクのコミットや完了報告へ毎回記載する運用を避ける。

## 完了条件（受け入れ条件）

- [x] 警告の内容は確認しつつ、具体的な影響がなければ定型的な記録を求めない方針を文書化する。
- [x] 検査失敗や必須要件違反の扱いを維持し、実装・評価手順と生成済みスキルへ同期する。

## スコープ境界

タスク管理文書、TypeScript規約、初動ガイド、実装・評価手順と生成物を対象とする。Biome設定や本番コードは変更しない。

## 確認

変更文書の点検、`npm run gen:codex:check`、`npm run tasks:index:check`、`npm run tasks:check`、スキルの `quick_validate.py` が成功した。変更MarkdownはPrettierで整形・確認した。本番コードを変更しないためビルド・動作テストは対象外とする。

生成時には、実装担当とタスクレビュー担当の生成物に残っていた「既存の正本」という表現も、原本の「既存のタスク文書」へ同期した。

ユーザーは、documents/rulesとdocuments/designの現在有効な文書を対象に、yomiyasuスキルで日本語を読みやすく整えることを求めている。本タスクでは下記の範囲を読み、主語と述語の不整合、直訳調の表現、重複語、不要な装飾を見直す。自然な表現はそのまま残す。

## 修正方針

実行時にyomiyasuスキルの本文と、文書に合うドメイン別の参照資料を読む。仕様・規約・手順にはbusiness、技術調査にはtechを目安に適用する。[Markdown規約](../../../documents/rules/coding-md.md)に従い、文体は簡潔な常体を基本とする。

元の主張、比重、断定の強さ、文の働き、評価の含みを保つ。必要な否定・条件・例外を削らず、意味が確定できない表現は推測で補わない。意味を確定するために必要な場合だけ、参照先や関連実装を確認する。

識別子、パス、URL、設定キー、数値・単位、数式、コマンド、引用原文は保持する。コード例は実行内容を変えず、日本語コメントを直す場合も意味を保つ。必須・推奨・任意の区別、手順の順序、表の対応関係を維持する。箇条書きや文長の数値目標のために、必要な一覧や条件を削らない。

見出しを変更する場合は、旧見出しへの参照を`rg`で確認し、対象文書内と参照元のリンクを同時に直す。参照元の編集はリンク修復に必要な箇所だけとする。設計内容を変えないため、APIや設定の同期は不要。

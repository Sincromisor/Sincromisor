# Mastra Studioのサインインと会話設定の操作ガイドを作成する

## 背景 / 目的

READMEの「管理画面の使い方」はAgentServerの設計資料を参照しており、サインインの入力値と会話設定の反映方法を初めて使う管理者が読み取りづらい。
ユーザーの依頼に基づき、READMEから操作ガイドだけを読んでサインインと指示の公開まで進める状態にする。
起票時はHEAD `b31be6ec`の設計、認証の組立て、トークン読込み、Composeの公開先を確認した。

## 完了条件（受け入れ条件）

- [x] `documents/guides/mastra-studio.md`に、対象者、起動済みのchat構成という前提、サーバーを動かすPCで開くURL、サインイン、指示の編集・試行・公開を操作順に記載する。
- [x] アカウント登録は不要であり、Email欄は`admin@example.test`、Password欄は管理者トークンを使うことを説明する。自動生成値の取得コマンドと実行場所、`.env`で`SINCRO_AGENT_ADMIN_TOKEN`を指定した場合の使い分けを示す。
- [x] Agentsから「Sincromisorのキャラクター」を選び、Editorで保存・試行し、Publish後に通常の会話へ反映されることが分かる。
- [x] 画面が開かない、サインインできない、編集が反映されない場合の確認先を示す。既定の公開先はサーバー自身のみであり、別PCのlocalhostでは接続できないことを説明する。
- [x] READMEの「会話の設定を変える」をガイドへ接続し、AgentServer設計の操作手順をガイドへの参照に整理する。認証・保存・公開済み指示の優先関係などの設計は維持する。

## 変更範囲と方針

新規ガイド、READMEの該当節、AgentServer設計を変更する。設計索引の説明に影響する場合は同期する。
本文は利用者の操作を主語にし、内部クラスやAPI契約の理解を前提としない。トークンは例・画像・検証ログに残さない。
認証方式、画面、ネットワーク公開範囲は変更しない。トークン変更とMCP接続の詳細は今回の対象外とし、必要なら既存資料へ案内する。
他のガイド化タスクへの依存は設けず、READMEの担当節だけを更新する。

## 確認方法

変更したMarkdownをPrettierで整形・確認し、リンク先と見出しを確認する。
URL、入力値、コマンド、手動指定トークンの優先順を現行実装と照合し、READMEから公開操作まで説明が途切れないことを通読する。
画面上の操作名が資料だけで確認できなければ、採用版の画面で該当部分を確認する。検証のために稼働中の指示を公開・上書きしない。
文書のみの変更であり、アプリ全体のビルド・テストは要求しない。

# 逐次音声対応を検証環境とVPSへ配備する

## 背景・目的

ユーザーから、完了した逐次音声対応をデプロイし、VPSについては非公開の運用メモを参照するよう依頼された。
音声合成のMessagePackが変わるため、下流のPythonと両ホストのGo RTCを同じ更新で切り替える。

## 範囲と手順

- コミット済みソース `88a169a6`からRTC・フロント・VoiceSynthesizer・VOICEVOXの必要4イメージを作成する。実会話で検出した問題の修正後、RTCのみ `833a5687`へ更新する。
  他サービスは既存の稼働用イメージを維持する。ビルド入力はGitから展開し、未追跡辞書や秘密設定を含めない。
- 運用メモの直接転送方式を使い、RTCイメージとソースをVPSへ転送してIDを照合する。レジストリ公開は行わない。
- 各ホストの現在ソース、設定、起動状態、保存領域、イメージを確認し、上書きせず今回専用の復旧記録を作る。
- VPSの会話セッション0を確認し、旧RTCと新Pythonの通信が混在しない順で切り替える。
- ローカルは既存の全体構成、VPSはRTCと共通ログ収集の6サービスを起動する。VPSの静的配信元も新RTCのフロントへ揃える。
- 稼働状態、Consul登録と下流到達、中央ログ配送、両公開入口からの会話・非無音の音声・テロップを確認する。
- 失敗時は原因を記録し、今回の上書き設定と退避イメージで復旧する。保存領域・辞書・journalは削除しない。

## 完了条件

- [x] ローカルとVPSの担当サービス・探索・中央ログが正常である。
- [x] 両入口からブラウザー会話が成立し、認識・応答・非無音音声・テロップを確認した。
- [x] 復旧情報、検査結果、残リスクを記録し、一時作成物と容量を確認した。

## 実施上の制約

SSH接続先、実アドレス、配置先、設定の実値、会話原本は `work/`へ保存し、公開タスクへ転記しない。
配備するコードの独立評価は [逐次音声対応](../../backend/task-261018204902-streaming-conversation-audio/eval.md) でPASS済み。
本タスクでは配備手順の独立レビューと実施記録の評価を行い、対象コードの再実装や無関係な全イメージ再ビルドは行わない。

### 稼働・会話確認

- ローカルは31サービスがhealthy、登録用1サービスが稼働、初期化4サービスが終了コード0。VPSは6サービスすべてhealthy。
- Consulは14メンバーalive、criticalは0件。VPSから下流4サービスを探索し、各状態APIへ接続できた。
- 両ホストから中央への新着RTCログを検索できた。収集・配送状態は正常で、破棄・配送エラーは0件。
- ローカルRTC・フロント専用サービス・VPS公開入口のHTMLと参照JavaScriptはSHA-256が一致した。
- Playwright CLIの専用Chromeと模擬マイクで実会話を確認した。測定時のローカルは認識1件・応答1件・テロップ1,037件・受信音声5,630パケット・音声エネルギー0.794197、VPSは認識2件・応答2件・テロップ1,990件・受信音声5,722パケット・音声エネルギー1.912008。双方RTC/ICE接続、非ミュート再生、ブラウザーエラー0件。
- 最終ログではローカル29要求・VPS17要求がすべて合成完了し、パイプライン再接続・合成欠落は0件。ローカルで送信時刻を過ぎた無音枠を1件省略したが、合成音声の欠落ではない。ブラウザー終了時の受信待ち切断は会話中の合成失敗と区別した。
- 検証ブラウザーを終了し、両RTCがセッション0・準備完了であることを確認した。

### 保全・後片付け・残る制約

設定、ソース、旧イメージ、静的フロントを非公開領域へ退避し、初回失敗時に実際に復旧した。現行構成の全マウントと変更対象外のイメージ参照、既存ボリュームの残存を照合した。モデル・辞書・journal・配送状態の保存領域は削除していない。ユーザーの未追跡辞書も維持した。

初回の不採用RTCイメージは両ホストで他タグ・全コンテナの参照がないことを確認して削除し、IDの残存も確認した。ビルド入力の一時展開、VPSの静的ファイル一時コピー、修正用ワークツリーを整理した。現行4イメージは稼働用、旧版の復旧タグと退避物は次回の正常配備と新しい復旧情報の確立まで保持する。

ローカルのDocker集計は開始前のイメージ105.7 GB・キャッシュ146.5 GBから、イメージ107.6 GB・キャッシュ148.7 GBとなった。キャッシュ増加は約2.2 GBで、既存ビルダーの回収設定（空き94.06 GiB以上、最大375.3 GiB）を維持した。最終空き容量はローカル107 GiB、VPS16 GiB。共有キャッシュや無関係のイメージを一括削除していない。

修正コードの対象race検査と独立評価はPASS。追加のGo全体race検査では対象外のICE収集試験に時間切れが残り、全体PASSとはしていない。詳細は修正タスクを参照する。今回の実環境確認では両入口の接続と会話が成立した。長時間・高負荷運転の保証は本確認の範囲に含めない。

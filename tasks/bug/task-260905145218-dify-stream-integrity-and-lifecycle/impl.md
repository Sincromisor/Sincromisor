# 実装メモ

- 同期HTTPをスレッドへ逃がす方式は取消後に読み取り担当が残るため採用せず、ロック済みの `aiohttp` をTextProcessorの直接依存にしてDify専用の非同期SSE生成器へ置換した。共有の同期 `process()` 契約は非同期アダプターで維持した。
- ローカル模擬HTTPで正常本文・感情コード・`message_end`、HTTP/Dify/EOF異常、読み取り取消、送信失敗、WebSocket切断を確認した。実Dify、GPU、利用者音声は未実行である。

親点検と独立評価で、失敗した受信処理の再送出が応答処理の取消を飛ばす不備と、`asyncio.run` の終了時回収が資源解放の未確認を隠す試験不足を検出した。両子処理を先に取り消して終了を待ち、同じイベントループ内でHTTP接続の終了と子処理の消滅を確認する回帰へ修正した。対象試験10件とGo互換1件、型・静的検査に再合格し、独立評価はPASS。実Dify・GPU・利用者音声はタスクどおり検証対象外とした。

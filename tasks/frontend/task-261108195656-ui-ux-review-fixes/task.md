# 設定画面の入力・説明・画面縮小時の操作を改善する

## 背景 / 目的

フロントエンド全体のUXレビューで、共通設定の操作に以下の不備を確認した。
Web UI・UX設計原則の入力保持、回復、アクセシビリティ、画面変化への追従を根拠に修正する。

| 優先度 | 問題                                 | 再現条件・影響                                                                               |
| ------ | ------------------------------------ | -------------------------------------------------------------------------------------------- |
| 高     | 低い画面で設定本文が隠れる           | 高さ320pxの詳細設定で固定操作欄が本文を覆い、機器選択ができない                              |
| 高     | 数値の打ち替えで別の値になる         | Looking Glassのタイル高さを消すと256になり、512と順に打つと2048になる                        |
| 中     | 説明が最初のクリックで閉じる         | ホバー・フォーカスで開いた直後、クリックで反転して閉じる。説明上にポインターも移せない       |
| 中     | 機器の選択表示が実値と一致しない     | 保存済み機器が一覧から消えると、既定機器へ戻したように表示される                             |
| 中     | 画面幅変更で操作位置が失われる       | 分類タブにフォーカスしたまま狭幅にするとフォーカスが本文全体へ落ちる                         |
| 低     | 空の履歴・支援技術向けの状態が不明瞭 | 空の履歴に案内がなく、スライダーの単位が通知されず、非表示のファイル入力も読み上げ対象になる |

## 完了条件（受け入れ条件）

- [x] 数値入力の空欄・負号・小数点を入力途中として保持し、確定時に既存の範囲制御へ渡す。取消・外部のプリセット変更も扱う。
- [x] 説明をマウス・タッチ・キーボードで開け、説明上のホバー中は保持し、Escapeと外側操作で閉じられる。
- [x] 不在の選択機器を選択欄に残し、既定機器への切り替えと一覧更新で回復できる。案内を入力へ関連付ける。
- [x] 分類表示のタブ・選択欄切り替えで操作位置を引き継ぎ、無関係な入力からフォーカスを奪わない。
- [x] 低い画面や文字拡大でも起動前・常設設定の本文と操作へスクロールで到達できる。通常の高さでは固定操作を維持する。
- [x] 空の会話履歴を明示し、スライダーは表示単位を読み上げ、ファイル選択の入口を一つにする。
- [x] 対象ブラウザー試験、型確認、静的検査を通し、レビューの確認範囲と実機で未確認の範囲を記録する。

## 設計判断・変更範囲

共通の入力・説明・分類・レイアウトを修正し、3種類の体験画面へ適用する。
数値の正規化、機器の所有者、保存形式、通信契約は維持する。
高さ不足時は固定配置より全操作への到達を優先する。

## 確認方法

再現条件をPlaywrightの回帰試験へ追加する。既存のトップ、起動、設定、診断選択、保存、フォーカス、体験終了の試験と照合する。
変更ファイルをBiome・Prettierで検査し、フロントエンドをビルドする。

## 文書同期

設定設計と共通枠組みへ、入力確定・機器不在表示・説明操作・高さ不足時の表示を反映する。
レビュー結果と確認限界は本タスクへ記録する。

今回の修正はUIの表示・操作に限定し、通信形式、設定保存形式、実機器の取得・解放処理は変更していない。
実機の音声会話、Looking Glass表示、各OSの権限ダイアログ、スクリーンリーダーによる読み上げは未確認。
アクセシビリティは名前・関連付け・状態・操作を確認した範囲の評価であり、WCAG全項目への適合を認定するものではない。

## 実装・確認結果

- 数値欄は入力途中の値を保持し、確定・取消・プリセット反映を共通部品で処理した。
- 説明の最初の操作とホバー継続、機器不在の選択表示と更新結果、分類のフォーカス引き継ぎを修正した。
- 高さ不足時の設定全体のスクロール、空の履歴、スライダーの単位、VRM選択の読み上げ対象を修正した。
- `npm run browser:test -- tests/main tests/ui tests/vrm --workers=1 --timeout=120000`: 31件成功。追加8件を含み、3ページの低い画面、数値・説明・機器・フォーカス、既存の開始終了・保存失敗復旧を確認した。
- `npm run test -- src/features/settings src/features/dialog src/features/conversation src/app/settings`: 19ファイル45件成功。
- `npm run build`: 型確認・本番ビルド成功。
- 変更したTypeScriptと試験のBiome、MarkdownのPrettier、`git diff --check`: 成功。
- 変更前の並列ブラウザー試験では再開始を含む3件が時間切れした。単独ワーカーと余裕のある試験時間で全件を完走し、製品コードの待機時間は変更していない。
- コメント点検: PASS。入力の確定境界、機器不在表示、フォーカス引き継ぎ、説明の終了条件、スクロールの所有範囲を点検した。

# 起動前の戻る導線と開始操作を整列する

## 背景 / 目的

左列の戻るボタンとリンクの縦積み、右列の下端揃えにより、開始ボタンと戻るボタンの位置・高さが揃わない。役割別に配置を整理する。

## 完了条件（受け入れ条件）

- [x] トップへ戻るリンクを概要・詳細共通の見出し付近へ配置する。
- [x] 概要・詳細切替と開始を同じ行・同じ高さへ揃え、狭幅は同幅の縦並びにする。
- [x] 開始の案内文は操作行とは別に配置し、有無や長さで片方のボタンだけがずれない。
- [x] 開始条件、説明との関連付け、表示切替後のフォーカス、トップへの移動を維持する。

## 変更範囲と設計判断

起動前設定の見出しと操作欄、必要な共通見出しの差し込み口とCSSを対象とする。ボタンの動作と開始制御は変更しない。

[設定UI設計](../../../documents/design/frontend/setting-and-debug-ui/settings-design.md)を配置仕様の参照先とする。枠の外寸は共通の親で揃え、スクロールは枠内へ置く。既存の固定操作と機器制御の意味を維持する。

## 確認方法

Playwrightで概要・詳細の広幅・狭幅、案内文あり・なしを確認する。既存focus.spec.tsと変更ファイルの静的検査・ビルドで操作を確認する。

## 設計文書の同期

設定UI設計に責務と確認方法をまとめ、共通枠組みから参照する。通信契約と保存形式への変更はない。

## 実装と確認結果

トップへのリンクを概要・詳細の見出し側へ移し、切り替えと開始を共通の操作行へ配置した。設定領域480px以下は同幅の縦並びにし、開始理由は別行で `aria-describedby` により関連付けた。1300・690・390・320px幅で概要・詳細をPlaywrightで測定し、両操作の高さ44pxと行または幅の一致を確認した。機器不在を設定モデルへ与えた長い開始不可案内でも整列と画面内への収まりを確認した。

既存 `focus.spec.ts` の広幅・320px幅の操作とフォーカス確認がPASS。変更TSXのBiome、CSS構文解析、型確認を含む通常ビルドが成功した。画像は `work/private-artifacts/settings-alignment-261025/` に保存し、広幅と320px幅を目視した。コメント点検を実施した。機器の実動作とバックエンドへの接続は実行していない。

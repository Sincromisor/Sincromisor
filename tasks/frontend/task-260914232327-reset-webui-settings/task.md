# WebUIの全設定を初期状態に戻す操作を追加する

## 背景 / 目的

不具合の切り分けに使える「全て初期設定に戻す」機能を追加するユーザー要求に対応する。
[通常設定の保存](../task-260914232323-persist-webui-settings/task.md)の完了後に実装する。音声・視線・姿勢の保存追加より先に、保存状態から復帰する操作を用意する。

## 完了条件

- [ ] 起動前ダイアログと開始後の基本設定から、共通の「全て初期設定に戻す」操作を実行できる。
- [ ] 削除対象と、再読み込みにより会話が終了することを実行前に示す。取消時は保存値・VRM・接続状態を変更しない。
- [ ] 現在のページだけでなく、同じオリジンでSincromisorが所有する全対象ページの保存設定を削除する。後続のデバッグ調整も同じ操作で削除できる範囲を定める。
- [ ] 前回選択したVRM本体とサムネイルを削除し、既定モデルへ戻す。元のローカルVRMファイルは操作しない。
- [ ] 通常起動のURL優先は維持するが、この初期化ではアプリが解釈する設定用パラメーター（現行は `talkMode`）を解除して同じページを再読み込みする。無関係なパラメーターとハッシュは保持する。
- [ ] 完了後は共通既定値とページ既定値・利用可否から初期化される。デバッグ調整、表示中のタブなどメモリ内の状態も再読み込みで初期状態へ戻る。
- [ ] 初期化中の保存通知や処理中のVRM保存・サムネイル生成により、削除済みデータが同じページから再保存されない。削除完了後に再読み込みする。
- [ ] 保存領域へのアクセス・削除失敗を成功として扱わず、失敗を表示して再実行できる。無関係な同一オリジンの保存データやキャッシュを削除しない。

## 設計判断と範囲

- 起票時の補完判断として「全て」は保存した設定に加え、VRM本体・サムネイルも含む。URL優先だけでは初期状態を作れないため、初期化時に限り設定用URLパラメーターを解除する。
- 全モデルを個別に書き戻す仕組みを増やさず、所有する保存データの削除と再読み込みで初期化する。OBS内では既存の自動開始契約を維持する。
- 削除対象キーを明示する。`localStorage.clear()` や全Cache Storage削除は使わない。ブラウザーの権限、配信素材、バックエンド設定・会話データ、利用者の原本ファイルは対象外。
- 破損・未対応形式でも操作から削除できる。設定エクスポート、段階的復旧、機能別リセットは追加しない。
- 保存処理だけを順序付ける最小の変更とし、RTCや追跡処理の終了機構全体を再設計しない。他タブを停止させる制御は対象外。

## 主な変更箇所

[設定層](../../../sincromisor-frontend/src/app/settings/)の削除窓口、[アプリ制御](../../../sincromisor-frontend/src/app/controller/sincroAppController.ts)、[共通設定UI](../../../sincromisor-frontend/src/features/settings/react/)、起動前後の設定ページへ接続する。
VRM削除は[ファイル保存サービス](../../../sincromisor-frontend/src/features/dialog/model/dialogVrmFileService.ts)と[選択処理](../../../sincromisor-frontend/src/features/dialog/model/dialogVrmWorkflowService.ts)、[サムネイル保存元](../../../sincromisor-frontend/src/character/scene/sincroVrmInitializer.ts)の処理中保存も含めて確認する。

## 確認方法

削除対象と保持する無関係なキー、URL変換、取消・削除失敗、保存処理中の初期化を対象テストで確認する。
開発ブラウザーで通常設定とテスト用VRMを保存し、起動前と開始後から初期化できること、既定モデル・ページ既定値へ戻ることを確認する。
変更範囲の静的検査とフロントエンドの型確認・ビルドを行う。

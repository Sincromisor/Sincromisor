# レビュー: task-261107202016-server-owned-voice-gate

## 判定

APPROVED

## 理由・申し送り

- 通常会話で音声を消さず、端末の学習VADを停止してサーバーへ判断を集約する要件は、承認済み方針に合う。音量表示・明示的ミュート・視線ミュートを維持する範囲も明確である。
- 現在のゲートは`UserMediaAudioProcessor`のGainNode、学習処理は`UserMediaVadRuntime`とWorkerクライアントが所有する。アプリ設定適用とデバッグ設定復元の両方から変更できるため、画面で操作を隠すだけでなく音声処理境界でも通常会話の方針を強制する必要がある。
- echoでゲートとVADの診断を維持することは既存のフロントVAD設計に合う。設定の復元、chat/sincroと診断モードの往復、停止と再接続を対象試験で確認できる。
- 同期先はフロントVAD設計、設定画面・診断項目の説明、音声折り返し手順とする。通常会話の実効状態と保存された診断設定を混同する表示を残さない。

## 自律補完

- `AUTO_FIX`: 通常会話の抑止は、保存値の復元とマイク開始より前から有効にする。設定復元やデバッグ操作で一時的に学習Workerを起動しない。
- `AUTO_FIX`: 診断用に保存したゲート・学習VADの選択は保持し、通常会話で一律に書き換えない。診断へ戻った際に再適用し、通常会話の実効状態は別に決める。
- `AUTO_FIX`: モード変更時には起動済みWorkerとPCM転送を停止し、遅着した学習結果をゲートへ反映しない。ミュートの所有者や音声トラックの終了処理は既存契約に従う。

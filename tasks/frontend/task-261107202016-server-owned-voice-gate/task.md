# 通常会話の音声送信からクライアントVADゲートを外す

## 背景と方針

サーバーが小声・語尾を含む音声から発話を判断できるよう、chat/sincroでは送信ゲートと学習VADを動作させない。スマートフォンの負荷を減らし、フロントは軽い音量表示を維持する。明示的ミュートと既存の視線ミュートの契約は維持する。

## 完了条件

- [x] chat/sincroは保存済み設定がゲート有効・learnedでも音声をVADで消さず、Silero Workerを稼働させない。
- [x] echoなどの診断では必要なVAD検証を維持する。モード切替・停止・再接続で通常会話へ診断設定が漏れない。
- [x] 通常会話のUIは実際に動作しないVAD設定を操作できるように見せない。音量表示、マイクミュート、既存フィルターは維持する。
- [x] 保存値の互換性、モード遷移、実際のゲートと学習処理の抑止を対象試験で確認し、設計・UI説明を同期する。

## 対象と確認

frontendのmedia/vad、appの接続・設定制御、設定画面と関連設計。サーバー変更と合わせて公開する。対象Vitest、型ビルド、Biome、全体ゲートで確認する。

## 実行結果

chat/sincroでは設定復元・マイク開始前にクライアントのVADゲートと学習VADを無効にし、保存値がlearnedでもWorkerを起動しない。echo/playbackの診断では保存設定を利用でき、通常会話へ戻すとWorkerとPCM転送を停止する。通常会話のVAD操作を非表示にし、軽い音量表示、明示ミュート、視線ミュートとフィルターを維持した。

関連62試験、型確認、Viteビルド、Biome、Markdown整形、構造検査、全体ゲートが成功した。独立評価でも設定復元・モード遷移・ゲートと学習処理の抑止を確認しPASSとなった。設計と変更理解範囲の日本語コメントを点検した。ブラウザー実操作、実端末の通信量・電力は未測定であり、実測による負荷削減を主張しない。

# 実装記録

## 判断と所有境界

アプリの開始・接続停止・体験終了を `SincroAppLifecycleController`へ抽出し、通常画面の操作を接続した。中核制御が開始世代を更新し、音声入力制御・カメラ制御・トラック所有者が後着結果を無効化する。使用状態は実トラックの所有者から通知するため、RTC停止中でも機器使用を示せる。

音声の元・加工済み・切り替え中トラックは同じ所有者が保持して終了する。AudioWorklet・追跡エンジンの初期化待ちにも終了後の再開ガードを置き、診断メーターのAudioContextも終了する。設定とモデルは保持し、RTCだけの既存停止窓口を変えていない。新しい説明文や確認ダイアログは追加せず、機器の実使用状態と異なる操作名だけを示した。

## 確認と残リスク

- 所有者間の結合テストで稼働中、取得待ち、加工待ち、マイク切り替え待ちの終了、後着解放、重複終了、設定からの再取得抑止、明示再開始を確認した。
- 既存のアプリ制御・設定テストと、追跡初期化待ちの終了を含むTrackerRuntimeテストに合格した。
- Playwright CLIとChromeの模擬マイク・カメラで本番の取得・音声処理・終了経路を通し、元・加工済み・カメラの全8トラックが `ended`、処理器と診断メーターのAudioContext4件が `closed`となることを確認した。320px幅のEnterによる終了、再開始、取得待ち終了も確認した。RTC設定は固定データで与え、実バックエンドの接続成功は確認していない。
- 実機のマイク・カメラとブラウザーの機器インジケーターは未確認。模擬取得の検証と区別する。
- 実RTCクライアントの接続失敗後に全体終了すると、閉じたPeerConnectionのtransceiverを再停止して例外になることを再現した。接続ごとの終了を冪等化し、重複停止の回帰テストを追加した。一つの所有者の解放が失敗しても残る所有者を解放し、最後にErrorのcauseへ原因一覧を保持して返す。
- 全体ゲートに合格。構造検査はコミット前の差分へ適用し、既存の例外は維持、新規例外は追加していない。文書・コメント点検はPASS。

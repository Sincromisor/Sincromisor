# トップページの冗長な補助ラベルを整理する

## 背景 / 目的

2026-10-24、HEAD `30ce9259`のトップには、通常2体験の選択肢の下に「声でつながる、ふたりの時間」「声も、しぐさも、もうひとりの自分」という補助コピーがある。画像と会話例の周囲にも「声で、もっと近くに。」「あなたの声から、物語が動く。」が重なり、開始操作の下には「ブラウザーから、あなたのペースで。」が添えられる。

ユーザーの原則に従い、選択肢・会話例・配置で伝えられる内容の補助ラベルを除く。過去のトップ説明ラベル整理は完了済みで、今回は現在残る別の表示を対象とする。

## 完了条件（受け入れ条件）

- [x] 通常2体験の選択肢では主ラベルと選択状態を優先し、上記の二次的なコピーを除く。説明のためだけの行高・空白も整理する。
- [x] 画像周辺の「声で、もっと近くに。」「あなたの声から、物語が動く。」と、開始操作下の「ブラウザーから、あなたのペースで。」を除き、画像と会話例の配置で伝える。
- [x] 紹介・開始手順・別表示の各節でも、見出しや図を言い直すだけの小見出し・補足を整理する。主見出しやFAQの利用条件まで一律に削除しない。
- [x] 音声診断の用途、折り返しでのヘッドホン使用、サンプル診断の確認対象、VRMの条件・保存範囲、専用機器・実験的機能の注記など、操作や利用判断に必要な情報は保持する。
- [x] 4体験の選択、二つの開始ボタンからの`talkMode`引継ぎ、下部紹介からの選択、会話例の切り替えが動く。狭幅の配置、代替テキスト、キー操作とフォーカス表示を保つ。

## 設計判断

補助文を別のアイコンやバッジへ機械的に置き換えない。既存の画像・会話例・ラジオ選択を使い、製品全体のコピー改稿や新規画像作成には広げない。

## スコープ境界

正式トップの冗長な補助ラベルと削除に伴う配置調整が対象。起動前・常設の体験入力は[体験選択の説明と再接続案内の重複を整理する](../task-261024195952-simplify-experience-guidance/task.md)で扱う。URL、FAQの仕様、サーバー要件、診断機能は変更しない。

## 実装方針

- [トップページ](../../../sincromisor-frontend/src/pages/main/index.html)の通常体験の`small`、`orbit-label`、`portrait-bottom`、`hero-footnote`と、紹介・手順・別表示の補助文を整理する。
- [トップCSS](../../../sincromisor-frontend/src/pages/main/styles.css)から不要な装飾・余白を除き、[体験切り替え](../../../sincromisor-frontend/src/pages/main/main.ts)が参照する要素と関係を維持する。
- [既存のトップ確認](../../../sincromisor-frontend/tests/main/main.spec.ts)の文言依存が変わる場合だけ更新する。

## テスト

変更対象の静的検査とビルド、既存のトップの選択・遷移確認を行う。`playwright-cli`で通常幅と狭幅を目視確認し、選択肢、会話例、開始操作、下部紹介の配置とキー操作を確認する。コピー削除だけを写す新規単体テストは不要。

## ドキュメント同期の要否

[ページ構成](../../../documents/design/frontend/pages.md)の表示説明が変わる箇所だけ同期する。URL・フォーム送信・体験値の契約は変更しない。

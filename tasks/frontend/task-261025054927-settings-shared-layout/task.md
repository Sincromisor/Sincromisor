# 設定本文と固定操作欄の幅と余白を統一する

## 背景 / 目的

本文だけに古い最大幅とスクロールバー用余白があり、操作欄との横幅がずれる。狭幅の余白・角丸も本文だけで変わる。共通設定の親が整列を所有する構造に直す。

## 完了条件（受け入れ条件）

- [x] 起動前の概要・詳細と基本設定で、見出し・本文枠・操作欄の左右端が揃う。
- [x] スクロールバーの有無で本文の外枠が狭くならず、本文と操作欄の内側左端・角丸が揃う。
- [x] カテゴリ切替で見出し・カテゴリ・固定操作が移動せず、長い本文と初期化操作に到達できる。
- [x] 起動前だけの最大幅・重複指定を整理し、共通3ページの設定表示を維持する。

## 変更範囲と設計判断

SettingsShell、起動前設定CSSと概要の枠を対象とする。操作の並べ直しは依存する別タスクで行う。設定値と通信は変更しない。

[設定UI設計](../../../documents/design/frontend/setting-and-debug-ui/settings-design.md)を配置仕様の参照先とする。枠の外寸は共通の親で揃え、スクロールは枠内へ置く。既存の固定操作と機器制御の意味を維持する。

## 確認方法

Playwrightで広幅・狭幅の短い本文と長い本文の外枠・余白・スクロールを確認する。変更CSSの構文検査、TSXの静的検査とビルドを行う。

## 設計文書の同期

設定UI設計に責務と確認方法をまとめ、共通枠組みから参照する。通信契約と保存形式への変更はない。

本文の表面をスクロール領域の外へ移し、操作欄と同じ幅・内側余白・角丸を適用した。起動前概要も共通の表面を使用し、詳細だけの998px制限と重複CSSを撤去した。３ページそれぞれ1300×970・390×970で概要・詳細の体験／画面・保存・基本設定をPlaywrightで確認し、枠の左右端と内側余白が一致した。代表ページの概要では長い本文のスクロール、詳細ではカテゴリ切替後の操作欄位置不変を確認した。画像は `work/private-artifacts/settings-alignment-261025/`に保存した。

変更TSXのBiome、変更CSSのPostCSS解析、型確認を含む通常ビルドが成功した。コメント点検を実施し、スクロール境界と狭幅の共通余白の理由を明記した。ボタン配置は依存する次タスクで修正する。バックエンドは未接続、機器は起動していない。

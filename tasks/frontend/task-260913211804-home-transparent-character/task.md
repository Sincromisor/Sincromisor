# キャラクターの背景透過とメガネ位置を調整

## 背景 / 目的

キャラクターを他の場所でも再利用できるよう背景と足元の影を透過し、赤いアンダーリムメガネを目を変えずにごくわずか上へ移動する。完成画像をトップページモックにも反映する。

## 完了条件

- [x] 背景に実際のアルファ値を持つ透過PNGを保存する。白い服・ソックス・靴は不透明のままとする。
- [x] メガネ位置をわずかに上げ、目とその他の外見を維持する。
- [x] モックの全身像と紹介カードを更新し、表示を確認する。

## 実装と判断

- [character-transparent.png](../../../sincromisor-frontend/public/images/home-mock/character-transparent.png) は1024×1536のRGBA PNGである。元の `character-glasses.png` を残し、HTMLとCSSの参照を差し替えた。背景色は既存のCSSで指定する。
- 内蔵 `image_gen` に背景透過とメガネ位置の微調整を指定して2回生成したが、どちらも格子模様を描画した不透明なRGB画像だったため採用しなかった。
- ユーザーがローカル画像処理への切り替えを明示的に許可した。既存環境のPillow・NumPy・OpenCV・SciPyを使い、元画像の背景色の連結領域を抽出し、髪や腕の隙間と足元の影も取り除いた。輪郭は元の背景色の混色を補正してアルファへ変換した。
- 赤いフレームの領域だけを抽出し、元の位置を補完して3px上へ移動した。その他の人物内部は元画像の画素を使用する。
- 処理スクリプトと明暗の背景での確認画像は `work/private-artifacts/task-260913211804-home-transparent-character/` に保存する。再調整時は元画像と同スクリプトを使う。
- `codex/home-ui-mock` ブランチ上で完了する。

## 確認結果

- PNGのアルファ範囲は0〜255。背景と元の足元の影は0、白いシャツ・ソックス・靴・脚の内部は255と確認した。
- 明るい背景・暗い背景で、全身の輪郭と髪の隙間、メガネの位置を目視確認した。
- `cd sincromisor-frontend && npm run build`: 成功。既存のVite設定と共通チャンク容量の警告は残る。
- playwright-cliで1440px・390pxの全身像と紹介カードを目視確認した。両方とも透過画像を読み込み、横はみ出し・実行時例外・HTTPエラーはなかった。
- コメント点検: PASS。全身表示と顔の切り抜きに関する既存コメントが現在の処理を説明している。操作ロジックは変更していない。

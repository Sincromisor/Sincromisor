# 開始前のデータ説明を共通モーダルへまとめる

## 背景 / 目的

開始前の概要と詳しい設定の各タブに繰り返される「データの扱い」を、必要なときに一度開ける説明へまとめるという利用者の要求に対応する。

## 完了条件

- [x] 概要・詳細の「トップへ戻る」の隣に「データの扱いについて」を表示する。
- [x] 音声・カメラ・VRM・設定の説明を共通モーダルへ移し、各タブの本文から取り除く。選択中の体験に応じた説明は維持する。
- [x] 閉じるボタン・Esc・背景クリックで説明だけを閉じ、開いた操作へフォーカスを戻す。選択タブと入力値を保つ。
- [x] 広幅と狭幅の表示、既存の初期フォーカスと起動前の配置を確認する。

## 実装と設計判断

`StartupMediaNotice`を説明本文として再利用し、`StartupDataNoticeDialog`を共通ヘッダーから開く。標準の`dialog`と宣言的な開閉を使い、追加の状態管理や依存は導入しない。起動前設定のEsc抑止に巻き込まれないよう、モーダルのDOMを`body`直下へ置く。閉鎖とフォーカス復帰はブラウザーに任せる。

権限拒否時の回復案内は既存の設定画面に残す。ヘッダーの補助ボタンが初期フォーカスを奪わないよう、選択中の体験を優先する。データの保存・送信処理、通信契約は変更しない。

## 確認結果

- 型検査、変更TS/TSXのBiome、フロントエンド構造検査が成功した。
- 既存の説明本文テストが成功し、4種類の体験ごとの保存説明を確認した。
- 新規のPlaywright試験が幅1440px・320pxで成功した。概要と全5タブの導線、説明の非重複、3種類の閉鎖方法、フォーカス復帰、入力保持を確認した。
- 既存のフォーカス・配置試験14件が成功した。共通3ページと狭幅の配置も維持した。
- 専用Chromeで広幅・狭幅のモーダルを目視確認した。
- 変更した部品と直接関連する処理のコメント点検: PASS。

確認はフロントエンドの表示・操作を対象とした。音声通信は今回の変更対象外であり、実サービスとの接続確認は実施していない。

# フロントエンドの補助ラベル調査

## 目的と判断基準

ユーザー要求の「言葉で説明せずに、UI要素とレイアウトで理解できるようにする」を基準とする。項目名・選択状態・数値・配置で既に伝わる内容を、別の見出しや説明文で繰り返す表示を修正対象とする。

まず入力や操作の名前、グループの境界、状態と操作の近さを整える。文言の一括削除、全項目のアイコン化、説明をすべて「?」へ移す方法は採らない。操作不可の理由・エラー・危険回避・利用条件・反映待ちなど、操作判断に必要な情報は対象に近い場所へ残す。

ローカルのRTC設定・診断APIは404で、マイク・カメラも列挙されなかった。接続中・機器選択成功・Looking Glass実機動作やエラー時の画面は実測していない。これらの状態にある重複は、表示コードに基づく指摘として区別する。画像は調査用の一時領域にのみ保存した。

## 見つかった修正対象

### カテゴリ名の再掲

設定は選択中の「マイク・音声」タブの直下へ同名見出しを置く。390px幅でもカテゴリ選択値の直下へ同名見出しが出る。診断の「Status」と本文の「STATUS」も実画面で重なっていた。現在位置は選択UIへ集約し、本文のアクセシブル名を維持する。

根拠: [設定の外枠](../../../../sincromisor-frontend/src/features/settings/react/shell/settingsShell.tsx)、[診断パネル](../../../../sincromisor-frontend/src/features/debug/react/panels/)。

### 共通設定の言い直しと選択値の再掲

「音量を自動で整える」に「マイク音量を自動で整えます。…」など、項目名と同じ意味の説明と利用例が常時付く。狭幅では各項目が複数行となり、同時に見える操作が少なくなる。

機器選択の「選択中: …」は、選択欄と同じ名前を再掲するコードがある。今回の環境では機器がないため、この成功時表示は画面未確認。機器不在などの案内は削減対象と区別する。

根拠: [音声補正](../../../../sincromisor-frontend/src/features/settings/react/fields/audioProcessingToggles.tsx)、[項目補足](../../../../sincromisor-frontend/src/features/settings/react/fields/settingsHelp.ts)、[機器選択](../../../../sincromisor-frontend/src/features/settings/react/fields/deviceSettingsFields.tsx)。

### 体験選択と再接続案内

通常の体験名に用途の言い直しが付き、常設設定には再接続の案内が二箇所ある。起動前の初回開始にも再接続案内が出る。選択名と文脈に応じた一度の案内へ整理する。

根拠: [体験入力](../../../../sincromisor-frontend/src/features/settings/react/fields/textSettingsFields.tsx)、[常設の追加説明](../../../../sincromisor-frontend/src/app/settings/react/sincroSettingsPages.tsx)。

### 起動前のモデル選択

「キャラクター」「VRM-1.0 モデル」、ファイル選択ボタン、独立したドロップ案内、現在モデルの状態が連続する。一つの交換操作領域へまとめ、対応形式と現在モデル・拒否理由は残す。

根拠: [モデル選択部品](../../../../sincromisor-frontend/src/features/dialog/react/components/dialogSettingsSections.tsx)。

### Looking Glassの反映案内

変更がない停止状態でも「反映タイミング」「変更の反映待ちなし」のカードと次回適用の固定説明が出る。変更時には値と詳細も同じ反映操作を説明するコードがある。停止・変更なしの表示はブラウザーで確認し、変更・再開始時の重複はコードで確認した。

根拠: [状態と操作](../../../../sincromisor-frontend/src/app/settings/react/lookingGlassControlPage.tsx)、[専用設定](../../../../sincromisor-frontend/src/app/settings/react/components/lookingGlassSettingsSection.tsx)。

### トップの二次的なコピー

通常2体験の選択肢の小さな副文、画像周囲の「声で、もっと近くに。」「あなたの声から、物語が動く。」などが主ラベル・画像・会話例と内容を重ねる。開始操作下にも「ブラウザーから、あなたのペースで。」がある。主見出しと機能説明・利用条件は保持し、これらの補助ラベルを削る。

根拠: [正式トップ](../../../../sincromisor-frontend/src/pages/main/index.html)。

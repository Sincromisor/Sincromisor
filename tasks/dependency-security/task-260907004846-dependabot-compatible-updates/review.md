# 依存更新方針の独立確認

## 目的と結論

2026-09-07に警告35件と更新方針を確認した。既存制約内の更新を進め、NeMoと旧音声認識の制約を強制的に上書きしない方針は妥当。実装後の確認結果は本書の対象外とする。

## 更新を保留する根拠

`uv.lock` が採用する `nemo-toolkit==2.6.2` の配布物のメタデータをuvキャッシュで確認した。`asr` の追加依存は次のとおりであり、警告修正版を通常の依存解決では採用できない。

- `hydra-core>1.3,<=1.3.2`。警告191の修正版1.3.4は範囲外。
- `lightning>2.2.1,<=2.4.0`。警告215の修正表示2022.6.15は、2.6.5まで影響するという説明と整合しない。[上流の修正](https://github.com/Lightning-AI/pytorch-lightning/pull/21832)は2026-07-14に統合されたもので、日付形式の版へ置き換える根拠にはならない。
- `transformers~=4.53.0`。警告211、147、144、87が要求する5系は範囲外。

確認した配布物は `nemo_toolkit-2.6.2.dist-info/METADATA` の754、755、759行。再対応条件は、修正を含む版と両立するNeMoの依存宣言が提供され、ReazonSpeechのモデル読み込みと音声認識を確認できること。

旧 `speech-recognizer` はuvのワークスペース対象外で、`transformers==4.51.3` を個別固定している。既存の依存宣言には4.52.3で `GPTNeoXAttention.hidden_size` が欠落する不具合が記録されており、実装は `nue_asr.load_model(..., use_deepspeed=True)` を使用する。今回、そのモデル実行を再現検証したわけではないため、固定解除の互換性は保証できない。

上流の取得先を `gh api repos/rinnakk/nue-asr/contents` で確認したがHTTP 404となり、上流の修正有無を検証できなかった。旧音声認識の警告210、146、143、86、29、28、27、20、19、18は維持し、取得可能な上流とDeepSpeedを含む実機推論の互換性を確認してから再対応する。

# 送信音声時計試験を責務別に分割

## 背景 / 目的

`internal/media/output/clock_test.go`は物理465行、import・コメント・空行を除いて約403行あり、送信間隔、遅延破棄、時刻折返し、欠番、符号化失敗、終了処理と偽時計一式が同居している。本番パッケージと試験配置を維持し、既存の観点に沿って試験ファイルを分割する。

## 完了条件（受け入れ条件）

- [ ] `clock_test.go`を送信間隔・遅延、時刻・欠番、失敗・終了の観点へ分け、共通の偽時計・偽符号器・偽トラックを試験補助へ集約する。
- [ ] 変更後の各試験ファイルを、import・コメント・空行を除いて300行以下にする。
- [ ] 試験は現在の`internal/media/output`と`output`パッケージに残し、試験都合の公開APIを追加しない。
- [ ] 20 ms間隔、250 ms遅延中止、無音、RTP時刻折返し、連続欠番、符号化・書込失敗、終了後の追加拒否という既存検証を削除しない。
- [ ] 移動した試験補助のコメント点検が完了している。

## 設計判断

本番コードは変更しない。偽実装を複製せず、同じ試験パッケージの補助ファイルから再利用する。

## スコープ境界

対象は`internal/media/output/clock_test.go`と直接の試験補助である。送信時計、符号器、キュー、テロップ生成の本番実装は変更しない。

## 実装方針

既存試験を観点ごとのファイルへ移し、共通補助だけを小さな試験補助ファイルへ分ける。試験名、入力、期待値は維持する。

## テスト

モジュールルートで`go test ./internal/media/output`と`go test -race ./internal/media/output`を実行する。

## ドキュメント同期の要否

試験配置以外の仕様を変えないため、設計文書の同期は不要である。

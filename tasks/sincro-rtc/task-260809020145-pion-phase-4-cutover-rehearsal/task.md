# Pion移行の会話経路を確認する

## 目的と確認条件

Pion移行の判断として、ブラウザーからの接続、利用者・応答の文字表示、テロップ、非無音の合成音声、通常終了とセッションの収束を確認する。
模擬応答の固定文字列を実サービスの判定へ流用しない。性能比較やブラウザーの組合せ試験は対象外とした。

## 判定と移行方針

初期試行では必須出力を確認できず、最終試行で上記の会話経路を確認しPASSと判定した。
aiortcの会話成立は移行条件から外し、Pion移行後の不具合はPion側で修正する方針とした。
当時の判断を要約したものであり、環境別の切替・運用記録は公開成果物から除外した。

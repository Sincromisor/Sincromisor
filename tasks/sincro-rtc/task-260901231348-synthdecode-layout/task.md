# 合成音声デコーダーを変換段階別に整理

## 背景 / 目的

`internal/media/synthdecode/decoder.go` は388行、`decoder_test.go` は453行あり、MIME解析、入力時刻検証、FFmpeg実行、PCM変換、モーラ境界変換、エラー分類が一つのファイルに集まっている。パッケージ境界は既に適切だが、ファイル単位の責務とコメント言語に不整合が残る。

## 完了条件（受け入れ条件）

- [ ] MIME / 入力検証、外部処理実行、PCM / モーラ変換、公開型を主要責務ごとのファイルへ分け、各本番ファイルを300行以下にする。
- [ ] 対応試験を同じ責務単位へ分け、既存の固定音声と処理実行担当の試験を維持する。
- [ ] 対応MIME、120秒・出力量・時間切れ上限、末尾無音モーラの丸め、有限エラー分類が変わらない。
- [ ] 外部処理の所有権、入力拒否条件、秒からサンプルへの変換を日本語コメントで説明し、英語だけの説明を残さない。

## 設計判断

既存 `synthdecode` パッケージを維持し、新しい階層やコーデック抽象化は追加しない。分割は現在存在する変換段階に限る。

## スコープ境界

対象は `internal/media/synthdecode` の本番コードと試験である。FFmpeg版、対応MIME、`pipeline` DTO、音声出力処理は変更しない。

## 実装方針

関数を大きく書き換えず、型・定数・変換関数を責務別ファイルへ移す。変更理解範囲のコメントだけを規約へ合わせる。

## テスト

`go test ./internal/media/synthdecode`、`go test -race ./internal/media/synthdecode`、`go test ./...` を実行する。

## ドキュメント同期の要否

公開仕様は変わらないため設計文書の変更は不要。既存パッケージコメントは分割後の導線と一致させる。

# RTCプロセス試験補助を外部境界別に分割

## 背景 / 目的

`cmd/sincro-rtc/process_harness_test.go`は物理352行、import・コメント・空行を除いて約316行あり、偽Consul、ポート・インターフェース確保、Pion接続、Offer送信、HTTP待機・検証を一つの試験補助ファイルに持つ。実プロセス試験の配置は維持し、外部境界ごとに補助コードを追えるようにする。

## 完了条件（受け入れ条件）

- [ ] `process_harness_test.go`をConsul・ネットワーク準備、Pion・Offer、HTTP状態待機・検証の境界へ分ける。
- [ ] 変更後の各試験補助ファイルを、import・コメント・空行を除いて300行以下にする。
- [ ] 試験補助は現在の`cmd/sincro-rtc`と`main`パッケージに残し、本番要素や専用の共通試験パッケージを追加しない。
- [ ] 既存のプロセス試験が利用するポート予約、唯一のIPv4インターフェース選択、Offer作成、`ready`・`draining`・セッション数・HTTP停止の待機条件を変更しない。
- [ ] 移動した外部境界と待機補助のコメント点検が完了している。

## 設計判断

本番の起動処理やプロセス試験本体は変更しない。補助関数を外部境界別の`*_test.go`へ移すだけとする。

## スコープ境界

対象は`cmd/sincro-rtc/process_harness_test.go`と、それを利用する同ディレクトリの試験に必要な参照調整である。`internal/gate3`、本番設定、Consul・HTTP・RTC契約は変更しない。

## 実装方針

既存の偽実装と補助関数を境界別ファイルへ移動し、呼び出し側の試験と待機期限を維持する。

## テスト

モジュールルートで`go test ./cmd/sincro-rtc`と`go test -race ./cmd/sincro-rtc`を実行する。

## ドキュメント同期の要否

試験補助の配置だけを変えるため、設計文書の同期は不要である。

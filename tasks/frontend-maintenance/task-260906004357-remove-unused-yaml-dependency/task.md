# フロントエンドの未使用YAML依存とビルド設定を削除

## 背景 / 目的

`js-yaml` は `package.json` の依存宣言と `vite.config.js` の分割設定に存在するが、フロントエンド実装からの読み込みが見つからない。

根拠はフロントエンドの肥大化レビューに対する改善タスク起票のユーザー要求である。起票時の確認基点は `75ebbdb4d562dfefbd5cbd887e121a8a0b9cc3bb`。実装着手時に現在のコードと呼び出し元を再確認する。

## 完了条件

- [x] 静的・動的読み込みとビルド設定を再確認し、未使用の `js-yaml` の直接依存を削除する。
- [x] 対応するロックファイルと `js-yaml` 専用の分割設定を同期する。推移依存として必要な場合はその依存まで強制削除しない。
- [x] 通常のフロントエンドビルドが成功する。

## 変更範囲と方針

ルートのタスク管理が使用する `yaml` は別の依存であり変更しない。他の依存の更新や一括整理は行わない。

- [package.json](../../../sincromisor-frontend/package.json)
- [package-lock.json](../../../sincromisor-frontend/package-lock.json)
- [vite.config.js](../../../sincromisor-frontend/vite.config.js)

## 依存タスク

なし。単独で着手できる。

## 確認方法

- rg で `js-yaml` の読み込みと専用設定の残存を確認する。
- ロックファイルの差分を確認し、無関係な依存更新がないことを確認する。
- `sincromisor-frontend` で `npm run build` を実行する。変更したソースの整形・静的検査は対象ファイルに限定する。
- 実行コマンド、確認結果、未実行項目と理由を本書に追記する。

## 文書同期

利用者向けの挙動と公開契約は変更しないため、設計文書の改訂は原則不要。削除対象を現行機能として説明する箇所があれば、その記述だけ同期する。

## 実施結果

通常変更として `npm uninstall js-yaml --offline --ignore-scripts --no-audit --no-fund` をフロントエンドで実行し、専用の分割設定を削除した。ロックファイルの差分は直接依存宣言、`js-yaml`、その依存先で他に利用のない `argparse` の削除のみ。

- `rg` で実装・依存宣言・ロックファイル・ビルド設定に `js-yaml` と `vendor_yaml` が残らないことを確認した。
- フロントエンドで `npx biome check package.json vite.config.js` と `npm run build` が成功した。500 kB超の分割ファイル警告は既存構成によるもの。
- 文書点検・コメント点検はPASS。実機画面確認は実装変更がないため未実施で、既知の残リスクはない。
- タスク索引検査は成功。タスク全体検査は1件目と同じ既存タスクの成果物3件欠落によって失敗した。

# 顔追跡の有効性を表情の強さから分離する

## 背景 / 目的

表情係数の最大値を顔の信頼度にしているため、無表情で正常に検出された顔も閾値を下回り、頭部追跡や較正を停止する。FaceLandmarkerは顔の検出確率を結果に返さないため、表情係数から確率を捏造しない。

## 完了条件

- [x] 正常な検出結果では表情の強さによらず追跡を継続する。
- [x] 未検出・空ランドマーク・非有限座標・不正な頭部行列は無効化する。行列省略時の既存の中立姿勢への代替は維持する。
- [x] 有効性の値はモデルの確率でないことを型・診断表示・設計へ明記する。
- [x] 正規化から頭部リターゲットまでの無表情・較正継続・追跡喪失を回帰試験で確認する。

## 範囲と確認

Face正規化、スナップショットの意味、診断表示、追跡設計を対象とする。ROIや追跡鮮度の評価は既存の信頼性層に残す。対象Vitest、TypeScript、Biome、Markdownとタスク整合性を確認する。実カメラの精度測定は対象外。

根拠: [公式Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker?tab=Web)（2026-11-07確認）。blendshapeは表情係数であり顔検出確率ではない。

## 実施結果

表情係数からの信頼度推定を廃止し、幾何入力の有効性を0/1で返す。無表情での頭部較正と追従、未検出・不正入力、行列省略を確認した。`npm run test -- sincroFace` は12件成功。TypeScript、対象Biome、Markdown、タスク整合性も成功。実カメラ測定は未実施。コメント点検: PASS。

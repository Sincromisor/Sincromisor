# Silero VADの状態と入力文脈を正しく引き継ぐ

## 背景 / 目的

同梱ONNXモデルは `output`、`stateN` の順で出力する。確率取得後の早期終了によって状態が更新されず、16kHz入力へ直前64サンプルを添える処理も欠けている。調査で再現したこの不具合を直す。

## 完了条件

- [x] 512サンプルへ直前64サンプルを前置し、返された状態を次の推論へ渡す。停止・再開時は状態と文脈を初期化し、古い推論結果を採用しない。
- [x] 同梱モデルの入力・出力契約を固定し、未知の形式は既存の代替処理へ通知する。
- [x] 正常化後の確率を同梱モデルで確認し、閾値の既定値・入力範囲・保存設定を同期する。
- [x] 状態引継ぎ・リセットの回帰試験、設定復元試験、型確認が通る。

## 変更範囲と確認

`features/media/vad`、音声プリセット、設定スキーマ、診断UI、音声VAD設計を変更する。フレーム間引きは次のタスクで修正する。RTC通信形式は変更しない。実マイクの会場別調整は完了条件に含めず、公式既定値を基準とした動作を確認する。

## 根拠

[Silero v6.2の公式ラッパー](https://github.com/snakers4/silero-vad/blob/v6.2/src/silero_vad/utils_vad.py)（2026-11-07参照）の16kHz入力、状態、文脈を採用する。

## 実施結果

固定入出力と状態・文脈の所有者を `SileroVadInference` に集約し、Workerの停止・再開を跨ぐ結果を拒否した。確率閾値は公式基準の0.5/0.35へ変更し、旧保存値のうち0.01未満は復元時に既定へ戻す。入力範囲変更は保存設定への互換性変更だが、RTC通信形式は変えない。

回帰試験と設定復元試験5件、TypeScript確認、変更対象のBiome・Markdown確認を実施した。同梱ONNXの無音10フレームの確率は約0.0017〜0.0089で、新しい開始閾値を超えない。実音声・実マイクでの閾値最適化は未実施。コメント点検: PASS。

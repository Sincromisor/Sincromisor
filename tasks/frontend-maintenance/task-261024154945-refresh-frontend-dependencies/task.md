# フロントエンドと共通開発ツールの依存を更新する

## 背景 / 目的

ユーザー要求に基づき、フロントエンドとルートの共通開発ツールの更新を取り込む。調査基準日は2026-10-24。

## 完了条件

- [x] npm公式レジストリで直接依存の安定版を確認し、依存定義とロックファイルを同期する。
- [x] MediaPipeの配布資産の準備、静的検査、型検査を含む本番ビルド、既存単体テストが成功する。
- [x] 採用版、見送り理由、未実行の確認を記録する。

## 変更範囲・判断

ルートと`sincromisor-frontend/package.json`、共有`package-lock.json`、必要な互換性修正を対象とする。ReactとReact DOM、Playwright関連は対応する版を揃える。既存のUI・設定・RTC契約を維持する。

Node・npm系列は維持し、その保守版とDockerビルド環境の同期はDockerタスクで扱う。機能追加、描画方式の変更、不要な依存追加は行わない。

## 確認方法・文書同期

指定されたNode・npm環境で`npm ci`、`npm run check --workspace sincromisor-frontend`、`npm run build`、`npm test`を実行する。依存更新で設計上の利用方法が変わる場合のみ該当文書を同期する。

# 実装上の判断と確認範囲

## 判断

メジャー更新を含めて公開安定版を適用した。Zod 更新で再現した既存のエラー分類回帰だけ本番コードを修正した。既存の大きなプロファイルファイル全体の分割は今回の依存更新へ広げず、構造検査の例外理由を当該ファイルへ記した。

## 未実行確認・残る制約

実サーバーとの会話、実カメラでの認識精度、Looking Glass 実機、HLS 実配信、ONNX による実音声推論、Docker イメージの構築は未実施。ブラウザー確認はローカルの本番ビルドと生成映像で実施した。静的配信には会話用 API がないため、会話ページの RTC 設定取得は404になる。実際の通話・実機品質まで検証済みとは扱わない。

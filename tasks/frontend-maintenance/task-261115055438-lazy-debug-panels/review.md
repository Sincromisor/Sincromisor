# レビュー: task-261115055438-lazy-debug-panels

## 判定

APPROVED

## 理由・申し送り

- 常設の音声・追跡DOMと遅延対象の表示用購読が区別され、初回非表示、再表示、失敗時の確認が指定されている。既存の `DebugConsole` とActivityの構成に沿って実装できる。
- 採否は先行計測で決める。現時点の承認は段階的なタスク仕様に対するものであり、`blocked` の解除や速度改善の確認を意味しない。境界を変更した場合は仕様レビューも更新する。
- `GazePanel` と `GazeDetails` は現在同じファイルにあり、常設側からの静的参照が詳細表示の依存を残す。必要な分離を本タスクに含め、追跡DOMとportal先を従来の位置に保つ。

## 自律補完

- `AUTO_FIX`: 診断表示の失敗でRTC・追跡を終了しないという既定要件に従い、遅延読み込みだけでなく表示部分の描画失敗もパネル内で受ける。未捕捉の描画例外は現在のReactルートの `onUncaughtError` から共通起動失敗処理へ届き、機器終了を引き起こすため、遅延対象に限定したエラー境界を置く。失敗時にも常設DOMを置き換えない。

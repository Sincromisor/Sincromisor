# レビュー: task-261017151032-separate-debug-tracking-dom

## 判定

APPROVED

## 理由・申し送り

- `CharacterGaze.getManager()` は取得した映像要素を保持し、RTC受信処理はトラック到着時に `rtcAudio` を取得する。Reactの常設部分がDOMを所有し、既存制御がストリームと追跡を所有する分離には根拠がある。
- 現在は `GazePanel` と `AudioPanel` の内部に対象DOMがあり、アプリ初期化はシェルの配置後に始まる。先行する購読安定化の完了後、枠・タブ選択と購読部分を分ける範囲で実装できる。
- 完了条件、対象外、設計の同期先は明確であり、根拠のない性能条件もない。各DOMの一意性だけでなく、初期化前に取得した参照と `srcObject` が開閉後も同じであることを結合確認とブラウザー操作で確認する。
- 視線プレビューの配置を維持し、タブ切替で要素を別の親へ移して再生成しない。カメラ停止・再取得や音声接続の失敗は解消してから完了する。コメント品質には [source-comments.md](../../../documents/rules/source-comments.md) を直接適用する。

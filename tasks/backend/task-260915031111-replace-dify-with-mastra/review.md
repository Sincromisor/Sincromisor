# レビュー: task-260915031111-replace-dify-with-mastra

## 判定

APPROVED

## 理由・申し送り

- chatの入口をMastraへ切り替え、Difyの実行コード・有効設定・手順を撤去する要件は、Dify運用負荷を解消するユーザー要求に基づく。既存のWebSocket・MessagePack・フロントRTC契約を維持し、`sincro`を外部生成なしで残す範囲も明確である。
- 設定キーの置換、Compose経路、破壊的なDify設定廃止、前提タスクのAPI契約への従属が具体的である。Dify環境・履歴・資格情報を削除せず、切替前に会話を終了して新しいセッションを開始するため、保存データの破壊を伴わない。
- 基盤、MCP、ストリーム変換を前提タスクへ分離しており、本タスクは実際の入口接続と不要コード撤去に限定される。通常会話、セッション隔離、MCP応答、Studio公開反映、切断時の生成停止、`sincro`単独起動を最小の結合経路で確認できる。
- 現在有効なDify参照を対象に設計・設定・起動手順を同期し、archiveと過去タスクは残す方針である。必須確認が今回の差分で失敗したまま完了しない条件も高リスク変更として十分である。

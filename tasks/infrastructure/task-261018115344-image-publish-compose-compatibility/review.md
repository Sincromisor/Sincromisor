# レビュー: task-261018115344-image-publish-compose-compatibility

## 判定

APPROVED

## 理由・申し送り

- 調査で判明した公開計画の失敗に対応するタスクであり、対象は公開スクリプト・回帰テスト・公開設計に限定されている。ビルドや実公開を起票・検証へ追加していない。
- 現行スクリプト、回帰テスト、公開設計、ルートから読み込むComposeを照合した。サンプル設定と全プロファイルの実Composeから、AgentServerを含む12件の自作イメージを読み取り確認した。ルートから読み込まないMinIO定義や、外部配布のLLMイメージは対象に含まれない。
- AgentServerのDockerfileはコンテキストを基準にリポジトリ内へ解決できる。log-observer・Vector・VictoriaLogsのDockerfile省略も現行構成と一致する。展開元の内外とコンテキストの内外を区別する拒否条件は、既存指定を維持しながら公開入力を制限できる。
- Vectorの `0.58.0` とVictoriaLogsの `v1.52.0` を更新先とする判断が明示されている。履歴タグ、Compose指定タグ、パッケージ名を分離し、固定タグの対象でも現行パッケージの削除保護を維持する。既存のUTC日時を含む履歴タグ、同じコミット・タグによる再開、全件送信後の順次更新は公開設計と整合する。
- 一時展開の所有と後始末、送信前の照合、失敗時停止、ダイジェストと匿名取得による観測は既存処理の維持として指定されている。必須検査の成功を完了条件とし、実Composeの読取りと模擬した書込みの確認に絞っている。
- 公開タグ選択の変更に対応する設計同期先が具体的で、完了条件は検証可能である。コメント規約は直接適用する扱いであり、省略を認める条件はない。

# 全サービスのログ発生箇所と診断の不足を棚卸しする

## 背景と目的

「全サービスを収集対象に指定する」だけでは、出力されていない失敗理由やブラウザー・ホストの障害まで記録されるとは限らない。
レビュワーが指摘した漏れを含め、[ログ基盤全体](../task-260921212053-victorialogs-foundation/task.md)の実装前に対象・不足・担当・確認方法を対応付ける。
このタスクは棚卸しと不足タスクの起票を担当し、全機能の実装を一つにまとめない。

## 変更範囲と方針

- `compose.yml`、`compose/*.yml`、各プロセス入口、サブプロセス、外部接続、フロントの`shared/logging/appLogger.ts`と呼出し元を追う。
- 対象を本タスクの`coverage.md`に記録する。発生元・必要なイベント/失敗理由・出力と収集経路・担当タスク・確認手段/結果を対応付ける。構成上の全サービス一覧と突き合わせる。
- 正常系の主要な開始・完了と、利用不能・起動失敗・通信断・取消・異常終了を確認する。全関数や音声フレームの逐次ログは要求しない。
- 未出力、出力済み未収集、診断不足、取得不能、未確認、確認済み、要件上の非収集を区別する。出力済みでも中央まで届いた証拠がなければ確認済みにしない。
- ログ用サービスも標準の`docker compose up`に含まれ、Consulの登録・発見・監視で扱う構成を前提に、ホストごとの中央/収集役割と全インスタンスの識別を点検する。
- 下表に既知の不足の担当を固定する。追加で見つかった必須の不足は既存タスクを具体化するか小さなタスクを起票し、最終結合確認の依存に加える。担当未定の「後で対応」で終わらせない。

## 網羅性の境界

- 外部ツールは少なくとも相手先・操作・開始/終了・失敗理由を対象にする。ツール入出力の全量やLLM内部推論を記録しない場合は、診断上必要な代替項目と秘密情報・容量などの根拠を表に残す。呼出し全体を対象外にしない。
- 分散トレース製品を必須にせず、会話IDと処理IDで辿れる範囲・辿れない境界を確認する。必要な関連付けが欠ける場合は修正を割り当てる。
- ホストはSincromisorの障害原因になり得るDocker・サービス管理・GPU/デバイス・メモリー・ディスク等の記録を扱う。無関係な他アプリの全文収集を網羅性の条件にしない。
- 会話・音声生成ログは既定有効の2設定を維持する。資格情報や音声バイナリの全量記録と混同しない。
- 配送の保証範囲は保持容量・原本の存在・送信成功境界ごとに示す。収集範囲の網羅性と絶対的な無欠落保証を同一視しない。

## 完了条件と確認方法

- [x] 構成の全サービスと上記の実行境界が表に含まれ、既知の各指摘に担当と再現方法がある。
- [x] 必須の不足に具体的な実装タスクがあり、依存に漏れや循環がない。
- [x] 非収集の理由が要求と矛盾せず、未確認を非収集へ付け替えていない。
- [x] [最終結合確認](../task-260921212106-distributed-logging-acceptance/task.md)が表の全必須項目の実行結果を合格条件にしている。

コードと構成を読み、タスク・リンク検査で確認する。起票・棚卸し段階で実機結果を捏造しない。
実装開始後は各担当が表の該当箇所へ確認結果を追記し、設計確定内容だけを`documents/design/infrastructure/logging.md`へ同期する。

## 実施結果

[網羅性表](coverage.md)にCompose全33サービス（標準includeは30）と起動ラッパー、内部処理、ブラウザー、ホスト、ログ基盤・配送、IDと非収集の境界を記録した。
各行に必要なイベント、静的確認で判明した不足、出力/収集経路、担当、再現方法を対応付けた。中央到達の実機結果は全行未確認のままとした。

外部エンコーダー、S3キャッシュの無言失敗、初期化・登録シェル、診断を捨てるチェック、ブラウザーWorkerの不足を既存担当へ具体化した。
最終結合確認は表の各行IDと実行結果を結び付ける。12タスクは既存の依存で全担当へ到達でき、追加タスクや依存変更は不要だった。
未追跡だった関連ログ基盤タスクの定義と既存レビュー記録も、参照先・依存関係を保存するため本タスクと同じコミットへ含める。

## 確認結果

- ComposeのYAMLを既存の`yaml`で読み、全16ファイルの重複なし33サービスと表C01〜C33が一対一で一致、標準12 includeの30サービスも包含することを確認した。
- 12タスクの依存を再帰走査し、欠落・循環がなく、最終結合確認から全担当へ到達することを確認した。相対リンク70件の参照先も存在した。
- `npm run tasks:check`、`npm run tasks:index:check`と対象MarkdownのPrettier確認を実行した。
- 文書点検: PASS。出力済み/未出力/診断不足/未確認と非収集・取得不能を区別し、未実装仕様を現在設計へ転記していない。
- 実機の中央投入・障害注入・2ホスト検証は本タスクの対象外のため未実行。各行の担当と最終結合確認で実施する。本番コードの変更はない。

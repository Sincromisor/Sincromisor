# ローカル開発環境のイメージ更新と分散サービスの動作確認

## 目的

利用者の依頼に従い、ローカル開発環境のCompose担当サービスを現行ソースと指定された第三者イメージへ更新し、正常に動作することを確認する。
先行するVPS更新で未確認だった下流探索・通常会話・中央ログ配送も、ローカル復旧後に確認する。

## 完了条件

- [x] 更新前の設定・イメージ・永続データを退避する。
- [x] `full,chat` の自作12イメージを現行ソースから作成し、第三者イメージを取得する。
- [x] 初期化サービスの正常終了と常駐サービスの起動、Consul登録・死活確認を確認する。
- [x] ローカルとVPSから会話経路を確認する。
- [x] 両ホストのログ配送と中央検索を確認し、先行VPSタスクと非公開運用メモを同期する。

## 方針

既存の設定・認証・モデル・保存ボリュームを維持する。コミット済みソースを展開してビルドし、取得・作成の成功を確認したイメージだけを反映する。
既存の公開ポートと管理VPN構成を使い、共有レジストリへの公開や依存バージョンの変更は行わない。

## 確認結果

ソース `011853c5` から自作12イメージを作成し、第三者7参照を取得した。設定で固定された版・ダイジェストは維持した。開始時に既存コンテナはなく、永続ボリューム21件を停止状態で退避した。GPUと既存モデルを確認した。[イメージ識別情報](artifacts/image-identifiers.json)のIDと全36コンテナの実イメージが一致した。

最新版SeaweedFSで既存バケットの作成が終了値1となり、S3初期化が止まる不具合を実機で再現した。`s3.bucket.list` の成功後に不足バケットだけを作成するよう修正し、認証値の検証と署名付き要求、不正キー拒否を維持した。
既存のS3結合試験には同一設定の再実行とオブジェクト保持の確認を追加し、起動診断行をHTTP本文と区別する読取りも修正した。

`node --test scripts/tests/runtime-shell-diagnostics.test.mjs scripts/tests/s3-bootstrap.test.mjs` は2件成功した。実SeaweedFSの隔離環境で初回作成・再実行・キー変更・再作成・保存データの保持・不正キー拒否を確認した。

両ホストのログ基盤は、過去のjournal欠落区間を退避・記録し、現在のカーソルと配送成功を確認して確認済みmarkerだけを解除した。原本・読取位置・配送バッファは削除していない。中央で両ホストの新着ログを確認した。
ローカルの欠落不明区間は2026-10-01 13:44:52 UTC〜2026-10-13 16:47:19 UTC。VPS側は先行タスク記録のとおりであり、いずれも過去の欠落件数は不明のままである。

常駐32サービスがrunning、ヘルスチェックを持つ31サービスがhealthy、初期化4サービスが終了値0だった。Consulは14メンバー全件alive、criticalは0件。消失した旧Redis・VOICEVOXコンテナの登録2件は、現行登録と旧コンテナ不在を確認して退避後に解除した。

ローカルのChromiumで通常の `chat` を開始し、認識結果と応答文239件、テロップ1,064件、受信音声5,529パケット、累積音声エネルギー0.122867を確認した。音声要素は非ミュート・再生中で、ブラウザーエラーは0件。入力はリポジトリの診断音声から生成した模擬マイクで、実音声・実写は取得していない。
初回は下流の準備前に接続して応答が返らず、再読み込みでは検証用音声入力を取得できなかった。全サービス起動後に検証用ブラウザーを再起動して成功した。

既存の `.env` は退避元と一致し、ユーザーの固有名詞辞書も変更していない。S3修正はバインドマウントされた初期化スクリプトへ反映されるため、アプリイメージの再ビルドは不要である。

VPS側も通常会話の認識・応答・非無音の合成音声・テロップが通り、6サービス全件healthyだった。両ホストのログ配送監視は破棄・エラー累計0、中央検索で直近5分の両ホストの新着ログを確認した。先行VPSタスクと両環境の非公開運用メモを同期した。

短い音声の繰り返し入力中は、両経路で `VoiceSynthesizer` 起点の `runtime_error` によるパイプライン再接続を各1回観測した。原因の確定と負荷耐性の保証は行っていない。1発話後に120秒の無音を置く入力でVPS経由を再確認し、1認識・1応答、テロップ1,707件、受信音声4,944パケット、累積音声エネルギー0.000804を確認した。この接続の再接続・ブラウザーエラーは0件だった。

実マイク・実カメラと長時間の負荷試験は未実施。模擬入力による基本会話とサービス稼働の確認結果である。過去のjournal欠落件数は不明のまま残る。対象スクリプトのコメントを点検し、構文・差分・対象ファイルの整形・タスク整合性を確認した。

# RTC出力フレームの反復確保を減らす

## 背景と目的

出力の nextFrame は無音中も20msごとに960サンプルの配列を確保する。セッション内の逐次符号化へ渡す一時音声なので、所有範囲を明記して再利用できる。

## 完了条件

- [ ] 出力PCM作業配列をセッション内で再利用する。
- [ ] 前回音声が無音や端数へ混入せず、口形・時刻・世代の既存テストが成功する。
- [ ] 固定入力のベンチマークでフレーム配列の確保削減を確認する。

## 変更範囲

internal/media/output のフレーム生成・所有フィールド・試験。エンコーダーが保持するコピーと通信データの所有権は変更しない。

## 確認方法

変更前後の無音フレーム生成ベンチマーク、対象の go test -race・go vet を実行する。

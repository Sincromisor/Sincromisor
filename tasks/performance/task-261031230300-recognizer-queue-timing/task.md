# 音声認識の待機と実行時間を分離して記録する

## 背景と目的

共有認識スレッドの待ち時間が見えず、recognition_processing の query_time は後続のローカル保存・S3転送を含まない。認識応答が遅い原因を推論だけと誤認し得る。

## 完了条件

- [ ] 専用スレッドへ投入してから実行開始までと、保存を含む実行時間を分離する。
- [ ] 成功・失敗を固定IDと時間だけで記録し、音声・認識本文・保存先を出さない。
- [ ] 未開始取消を実行扱いせず、既存の直列実行・取消回収を維持する。

## 変更範囲

recognizer_execution.py の実行境界とテスト、SpeechRecognizer設計。推論方式・暫定結果の頻度・保存契約は維持する。

## 確認方法

固定時計と偽認識器で待機・実行・例外を確認し、既存の取消テストと対象のRuff・型検査を実行する。

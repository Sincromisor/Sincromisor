# 体幹を反映した最終姿勢の比較

## 確認範囲

既存6録画610フレームを、腕の比較と同じモデル・観測時刻・155ms補間で本番の最終姿勢まで再計算した。
[集計](comparison-summary.json)と[入力・出力の照合記録](../../task-261008235702-motion-filter-response/artifacts/evidence-manifest.json)を残した。
実写と比較画面はGit管理外の `work/private-artifacts/task-261008235703-canonical-torso-application/` に置く。
原本と未加工の再計算結果は照合記録のパスを参照する。

| 録画                 | フレーム数 | 体幹回転の最大値（rad） |
| -------------------- | ---------: | ----------------------: |
| 静止                 |        110 |                  0.0771 |
| 両腕上げ             |        101 |                  0.1032 |
| 片腕上げ             |         92 |                  0.1146 |
| 速い手振り           |         84 |                  0.1435 |
| 腕の交差             |        134 |                  0.2866 |
| 手の画面外移動と復帰 |         89 |                  0.1194 |

全610フレームで体幹の回転を生成し、到達距離の制限は0件だった。
肘反転拒否は手振りで1件、ほかは0件で、腕の比較基準と同じだった。
これは目視品質の点数ではなく、制約の診断値である。

同じ時刻の原動画、変更前、変更後を並べ、交差6500ms、両腕上げ7000ms、手の復帰4500ms、手振り5000msを目視確認した。
再計算サンプル時刻はそれぞれ6458.1、7000.5、4502.4、5068.3msだった。
変更後は肩線に応じた小さな体幹の傾きが加わる。腕の交差や両腕上げが原動画へ十分一致しない問題は比較前から残り、今回も解消していない。
手振り中の手はぼけており、指の開閉精度はこの画面から判断しなかった。

既存動画には大きな前後傾斜・旋回の品質を評価できる区間が十分ないため、実写品質は未確認とする。
既知の剛体回転を正規化入力へ与える固定テストで前後・横・旋回・複合回転を確認した。
平行移動だけでは回転せず、腰欠損では前後傾斜を作らず、顔の回転を体幹へ使わない。
任意の胸ボーンの有無にかかわらず、配分後の回転積が元の合計回転と一致する。
実IKのテストでは親ボーンを回しても体幹相対の腕解を二重に補正しないことを確認した。

最終姿勢の書き込みは既存の一括適用を使い、首・頭部の所有権を追加しない。
比較画面では最終姿勢を書き込むだけでライブの顔制御を動かしていないため、顔との見た目の同期精度は保証しない。
頭部・口形の独立制御は既存の管理側テストで回帰確認した。

再計算は[比較用入口](../../task-261008235702-motion-filter-response/artifacts/replay-browser.ts)で
`motion-final` をラベルに指定する。手のある3区間は `motion-final-hands` として保存済みHand・Gestureを併用した。
[集計関数](summarize-comparison.js)をPlaywright CLIの `run-code` に渡して集計する。

# 体幹の三次元姿勢を上半身ボーンへ配分する

## 背景・目的

腕は体幹の共通座標を使うが、本番の体幹反映は`torsoLean`・`shoulderRoll`・画面中心からのずれに依存し、脊柱・胸のX回転は常に0となる。`AvatarMotionProfile.torso.distribution`と`chestFollow`も本番の追跡層へ十分に接続されていない。姿勢合成のコメントにある`upperChest`への配分は、現在の`createTrackingPose()`では実施されていない。

[座標の修正](../task-261008235701-motion-coordinate-consistency/task.md)後の体幹基底を使い、利用者の体の向きと傾きをモデルの上半身へ反映する。

## 完了条件

- [x] 信頼できる肩・腰から推定した体幹基底の回転差を中立姿勢に対して求め、VRMの正規化済みローカル回転として上半身へ反映する。画面内の平行移動だけで体幹が回転しない。
- [x] 既存プロファイルの体幹配分を`spine`・`chest`・`upperChest`へ適用し、存在しない任意ボーンの分を存在するボーンへ配分する。配分の合計回転と順序を確認し、同じ回転を重ねて適用しない。
- [x] 顔の向きを体幹の向きとして強制しない。腰が見えない上半身入力では得られる肩情報だけで制限付き反映を行い、観測のない前後傾斜を推測で作らない。
- [x] 腕IKの肩座標と、回転後の親ボーン座標を揃える。体幹回転が腕へ二重に掛からず、首・頭の独立制御と単一の上半身書き込みを保つ。
- [x] 既存録画の該当する動作区間で、体幹・頭部・腕の整合を比較する。新たに表現できる動きと、録画で確認できない動きを分けて記録する。

## 範囲

全身移動、足接地、物理演算、腰位置の追従は追加しない。既存の骨盤位置固定と顔・口形の動作を維持する。正面からの腕上げだけで前後傾斜の品質が確認できたとはしない。

### 主な変更対象

- [体幹リターゲット](../../../sincromisor-frontend/src/character/retargeting/sincroPoseRetargetUpperBody.ts)と`SincroPoseRetargetFrame`の必要な入力
- [本番追跡層](../../../sincromisor-frontend/src/character/runtime/sincroVrmPoseComposer.ts)、既存の`vrmPoseTorsoFallback.ts`の配分処理
- `avatarMotionProfileTypes.ts`とIKの親座標変換の利用箇所

## 確認方法

既知の剛体回転を与えた肩・腰入力で前後傾斜・横傾斜・旋回を確認する。相対関係を保った平行移動、腰欠損、任意ボーン欠損を検証する。既存録画で対象動作が確認できる範囲を、同じモデル・同じ時刻で修正前後比較する。実写にない動作の品質は未確認とする。

## 実装・確認結果

肩・腰の共通基底から体幹回転を求め、プロファイルの追従量と配分で脊柱・胸・上胸へ反映した。
欠ける任意ボーンの分は存在するボーンへ再配分し、画面内移動と顔の向きを使わない。
腰欠損では肩から得られる旋回・横傾斜だけを制限付きで反映する。
体幹相対の腕IKは読込時の親座標で解き、最終骨格で親回転を一度だけ適用する。

既知の剛体回転、平行移動、腰・任意ボーン欠損、配分後の回転積、IK親回転を固定入力で確認した。
既存6録画610フレームと同一時刻の4画面を比較し、[比較結果](artifacts/comparison-results.md)に記録した。
大きな前後傾斜・旋回とライブの顔同期の実写品質は未確認。腕上げ・交差の既存の不一致は残る。
設計とコメントを同期し、骨盤移動・足・頭部・口形の所有範囲を変えていない。

共通の姿勢合成・IKの変更を含むため、依存する5タスクの実装・比較結果・状態を同じコミットにまとめる。
フロント全体のテストは677件成功・3件スキップ、型検査と本番ビルド、構造検査は成功した。

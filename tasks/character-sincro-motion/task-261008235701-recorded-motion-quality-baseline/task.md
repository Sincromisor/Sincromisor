# 既存撮影データでモーションの再計算比較と表示品質評価を整える

## 背景・目的

過去の6動作の実写動画・記録が`work/private-artifacts.macbook/`に提供された。起票時にファイルとハッシュ、保存項目を確認したが、現行版を再計算した基準値はまだない。また、`neutralJitter`は入力側の手首座標を測っており、VRMの最終姿勢の揺れや追従遅れを評価できない。通常再生は保存済みの共通表現・時系列状態を採用するため、そのままでは計算ロジックを変更しても比較対象へ反映されない。

撮影済み入力を固定して現行版と候補版を比較できる最小の評価経路を作る。既存の録画・再生・指標計算を拡張し、別の評価基盤を新設しない。

## 完了条件

- [x] [起票時の入力目録](./artifacts/recording-inventory.json)の6動作を使い、SHA-256と対応する原本を照合して比較区間を決める。Pose・Faceの生結果は保存済みだがHand・Gestureの生結果は無く、手・指の評価に必要な区間だけを同じ動画から再推論する。
- [x] 保存値の閲覧を維持した上で、入力観測から現在の処理を再計算する比較経路を用意する。変更する段階と下流の保存値は比較計算に再利用しない。生の結果、正規化済みスナップショット、動画のどれから開始したかを出力に残す。
- [x] 共通計算→本番リターゲット→姿勢合成→適用予定の`finalPose`を同じ入力時刻で評価する。履歴は各条件の先頭で初期化し、同じ入力を異なる条件へ交互に流して履歴を共有しない。
- [x] 最終ボーン回転の静止時の揺れ、動作区間の追従遅れと振幅、欠損復帰時の最大回転差を比較できる。クォータニオンの符号反転を姿勢差として数えず、時刻差・対象ボーン・集計区間・有効標本数を明示する。既存の到達制限・肘反転の診断も併記する。
- [x] 遅れは同じ処理系列の入力動作と出力動作の時間差として定義し、撮影から画面表示までの絶対遅延や人体の正解姿勢とは呼ばない。姿勢が停止して振幅が消えた候補を「揺れが小さい」として採用しない。
- [x] 現在のHEAD・モデル・VRM・設定・入力・時刻列を記した基準結果を残す。既存記録は中央値約93〜155ミリ秒間隔のため、動画の約30fpsで時刻を作り直さない。動画からの推論は一度保存し、その同じ観測列を比較に使う。推論自体を変更する比較は区別する。

## 実装方針と範囲

入口は開発者向けの既存再生APIか小さな実行スクリプトでよい。通常再生の保存値優先契約を変更せず、再計算を明示指定する。再生ログの意味・版を変える場合は読み手、書き手、旧ログの扱いを同期する。

調整用区間と最終確認用区間を既存録画の範囲で分ける。区間を分離できる長さがなければ同一録画への適合であると記録し、一般化を主張しない。回帰基準は現行版との比較から決め、根拠のない新しい数値目標を追加しない。

実写は`work/private-artifacts.macbook/task-260705214026-canonical-temporal-arm-solver-production/video/`と`replay/`を直接読み、原本を変更しない。新しい未加工結果は`work/private-artifacts/<本タスクID>/`へ保存する。人物を含まない既存の12秒の合成動画は、読み込み・保存・停止の確認に限る。

## 確認方法

保存値と再計算値が異なる固定入力で、閲覧と比較を取り違えないことを確認する。一定回転、符号だけが反転した同一クォータニオン、既知の遅れ・振幅を持つ系列で指標を確認する。提供済みの既存6動作の利用可能な区間を同じ条件で再計算し、実写の並列表示または動画とVRMの対応時刻を目視する。ブラウザー確認時は`playwright-cli`を使う。

再計算経路は複数の状態保持処理を接続するため、独立レビュー・評価の対象とする。

## 実装・確認結果

通常の保存値閲覧を維持し、明示した `recompute`と固定観測比較関数から本番計算を再実行できるようにした。
条件ごとに履歴を作り直し、生結果から最終合成まで同じ観測時刻で計算する。
最終回転の符号を同一視する差分・角速度・振幅・系列内遅れ・復帰角差を実装し、
一定姿勢と既知の遅れ/振幅の固定系列、保存値と再計算値が矛盾するログで検証した。

原本12ファイルのハッシュを照合し、6動作610フレームをHEADと候補で比較した。
動画の必要な3区間からHand/Gestureを118観測だけ保存し、同じ観測列を両版に使用した。
2種類の加工欠損も比較した。調整/最終確認区間、手の再推論区間、加工欠損区間を分けて集計した。
人物を含む目視画像・動画・生の出力は非公開領域に置いた。

結果、限界、再実行手順は[比較記録](artifacts/comparison-results.md)、
機械可読の値は[集計JSON](artifacts/comparison-summary.json)にある。
静止時の揺れや交差・挙上の最終表示は改善済みとは判定していない。今回の成果は比較経路と基準値である。
元のPose/Faceモデルハッシュの欠落、同一録画内の評価、低相関区間の遅れは限界として明記した。

コメントと保存値の扱いを点検し、モーション設計・追跡設計へ同期した。
共有する橋渡し・時計・合成を同じ最終姿勢で検証するため、依頼された3タスクを一つの統合コミットにまとめる。
独立レビュー・評価を実施した。全体確認は[評価記録](eval.md)を参照する。

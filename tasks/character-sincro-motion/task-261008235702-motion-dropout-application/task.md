# 腕の欠損予測と復帰を最終姿勢まで反映する

## 背景・目的

時系列処理には短時間予測・中立への復帰・再検出時の補間がある。しかし`createPredictedArm()`は見失った現在観測の信頼度を予測値に設定し、橋渡し処理がさらにその信頼度を乗算する。信頼度0の欠損では`predicted`なのに適用重み0となった。また、全体のPose未検出はリターゲットの早期中立復帰で処理され、腕ごとの時系列状態へ到達しない。

欠損処理を状態の記録だけで終わらせず、最終姿勢まで一貫して反映する。

## 完了条件

- [x] 観測の信頼度と、最後の有効な姿勢を短期間維持・予測するための適用重みを区別する。観測信頼度0の短い欠損でも直ちに予測姿勢の重みを0にせず、経過時間に応じて減衰させる。観測が回復したように信頼度を偽装しない。
- [x] 一時的な未検出・低信頼度と、追跡無効・明示停止・`chat`切替・顔のみへの切替を区別する。明示停止後に予測を続けず、一時的欠損では左右を独立に扱う。
- [x] 観測の無到着と「未検出」の到着の両方で、最後の有効観測からの経過時間に応じて保持・予測が終了し、腕を下ろした代替姿勢へ連続的に戻る。同一入力の再描画で予測時間や履歴を二重に進めない。
- [x] `dt > maxFilterDtMs`を積分へそのまま使わず、同時に欠損年齢を0のまま凍結しない。時刻逆行、再生の飛び越し、入力切替では該当系列の状態を初期化する。
- [x] 復帰の補間・IK重み・最終角速度制限の適用順を整理し、復帰完了の1フレームだけ跳ねないことを最終ボーン姿勢で確認する。時間上限は既存設定を出発点にし、変更時は既存録画の根拠を残す。
- [x] 全体の`frame.active`だけで片腕の有効性を潰さず、部位別の代替姿勢と追跡姿勢を合成する。頭部・口形の独立した更新を妨げない。

## 範囲と所有者

観測と時系列状態は`SincroMotionObserveOnlyPipeline`、腕の変換は`SincroPoseRetargeter`、最終姿勢の履歴は`SincroVrmPoseComposerService`が持つ。欠損時間の基準は最後の有効観測時刻に置き、現在時刻との対応は入力境界で明示する。描画の秒単位差分と推論のミリ秒単位時刻を混ぜない。

### 描画時刻との接続

時計の対応は`VRMCharacterManager.update(nowMs)`を単一の消費境界とする。供給側の`sincroCharacterMotionEventSink`とmotion-debugの追跡・再生接続は、PoseとHandそれぞれについて観測の`mediaTimeMs`と受信側の`receivedAtPerformanceMs`を組で渡す。受信時刻が無いライブ入力はその受信時に採時し、FaceやGestureの更新でPose・Handの対応を上書きしない。この対応値は実行時だけの入力とし、保存済みログの時刻を変更しない。

ライブでは各入力について`最新mediaTimeMs + max(0, nowMs - その入力の受信時刻)`を表示評価時刻とする。最後の有効観測の時刻との差で欠損年齢を求め、未検出の到着で有効観測の時刻を更新しない。再生・比較では壁時計を使わず、再生元が明示した仮想の現在時刻をそのまま渡す。停止した再生の時刻は進めず、無到着試験だけは入力を固定したまま仮想描画時刻を進める。

観測フィルター・意図推定はPose到着時だけ更新する。`SincroPoseRetargeter`は入力系列ごと・左右ごとに最後の有効な腕状態とその観測時刻を保持し、新しい有効観測でだけ更新する。無到着時の表示は、この固定した基点から現在時刻までを評価する純粋な予測として求める。毎描画の予測結果を次の観測や予測基点に戻さず、既存の予測・減衰の計算を共有する。指側にも同じ時計対応を渡し、独自の採時経路は作らない。

同一時刻の再描画では履歴を進めない。時刻逆行、入力ソース切替、再生の非連続な移動では対応値と表示側の最後の有効観測を破棄する。`chat`切替・追跡停止・顔のみへの明示切替では表示予測を終了し、VRM交換では腕・合成・指の履歴を初期化する。実行時の入力系列識別で切替を伝え、Poseが次に到着するまで停止を延期しない。

### 部位ごとの合成

既存の`SincroPoseRetargetedArm.active`を左右の利用可否として使い、追跡層を体幹・左腕・右腕に分ける。腕の保持・予測が有効な期間はその側の追跡層を有効にし、期限後はその側だけ既存の腕を下ろした代替姿勢へ戻す。`frame.active`だけで左右の重みを同時に落とさない。最終角速度制限と`normalizedPoseWriter`による一括適用は維持する。

## 確認方法

既存の左右の遮蔽・復帰固定入力を利用する。さらに、有効観測→片腕欠損→全体未検出→復帰と、観測が来ないまま描画だけ続く系列を、時系列推定から本番合成まで通す。既存録画のフレーム削除・欠損置換でも比較し、加工した試験であると記録する。保存した時系列値だけの検証で完了しない。

複数の状態所有者と停止境界を変更するため、独立レビュー・評価の対象とする。

## 実装・確認結果

観測信頼度と適用重みを分離し、観測到着時と無到着描画時で減衰予測を共有した。
左右の最後の有効観測を表示側の基点にし、予測結果を基点へ戻さない。
Pose/Handの独立した時計対応と入力系列番号を導入し、停止・顔のみ・モード切替・逆行・再生移動で履歴を破棄する。
IKの復帰補間済み姿勢へ進捗や適用重みを二重に乗算せず、体幹・左右腕を分けた最終合成で一度だけ重みを使う。

実際の二関節IKを使う結合テストで、有効→片腕欠損→全体未検出→無到着による左右別期限切れ→復帰を
最終ボーン姿勢まで確認した。同一仮想時刻の再描画、1000msの観測間隔、時刻逆行、明示無効、
Pose/Handの時計分離と停止した再生時刻も確認した。復帰完了を含む最終回転差は既存の角速度制限内だった。
頭部・表情・口形などの独立更新も既存の管理側テストで確認した。

既存録画16フレームの削除/未検出置換を比較し、[比較記録](../task-261008235701-recorded-motion-quality-baseline/artifacts/comparison-results.md)へ加工条件と限界を記した。
既存の左右遮蔽・復帰固定入力は生成コマンドで同期し、再生成の決定性と回帰基準を維持した。
変更した停止境界・予測・重み・合成のコメントと設計を点検した。
指の保持期限自体の修正やモーション全体の表示品質改善は本タスクの範囲外である。
独立レビュー・評価と全体確認は[評価記録](eval.md)を参照する。

# 既存録画で腕の揺れと追従遅れを両立する

## 背景・目的

腕にはOne Euro Filter、リターゲットの155ミリ秒の指数平滑化、最終姿勢の角速度制限が重なる。一方、`bodyLocalWrist`はフィルターを通るが、通常観測時の`bodyLocalElbow`は未平滑の値を使う。IKの肘方向の揺れを後段全体の遅れで抑えている可能性がある。これは構造上の仮説であり、実写の遅延改善量は未計測。

## 完了条件

- [x] [比較経路](../task-261008235701-recorded-motion-quality-baseline/task.md)で現行版、入力側の平滑化を整理した候補、必要最小限の描画補間を使う候補を同一録画・設定で比較する。候補を無制限に増やさず、各段階を変更する理由を記録する。
- [x] 手首と肘方向の平滑化・IKの極の履歴・描画補間が何を安定させるかを明確にし、同じ雑音に重複して強い平滑化を掛けない。One Euro Filterは実際の観測時刻差で更新する。
- [x] 同一Poseを繰り返し描画しても観測フィルターや肘の履歴を新観測として更新しない。描画間の補間と最終角速度制限は描画時刻で進める。
- [x] 静止時の最終姿勢の揺れ、腕上げ・手振りの位相遅れと振幅、交差時の肘方向、欠損復帰を比較する。揺れだけを減らして動きを潰した候補は採用しない。
- [x] 実測で有効な候補だけを既定値へ反映し、不要となった重複処理を削除する。有効性が確認できなければ現行設定を維持し、比較結果を結論として残す。

## 範囲

新しい学習モデル、Kalman Filterの追加、未来フレームを使う平滑化、大規模な自動最適化は行わない。現在のOne Euro Filterと二関節IKを使う。通常の本番処理は因果的に動作し、録画の将来フレームを参照しない。

## 確認方法

一定時刻列の同一観測について、観測間の描画回数だけを変えたときに観測状態が一致することを確認する。既存6動作のうち静止・ゆっくりした腕上げ・速い手振りを調整と確認に利用し、利用可能なら交差・復帰区間も回帰確認する。繰り返しの表示が必要なら同じ録画を再生し、追加撮影しない。

状態更新頻度と履歴の責務が変わる場合は独立レビュー・評価の対象とする。

## 実装・確認結果

現行、肘入力の平滑化、同候補と40ms描画補間の3条件を既存6録画で比較した。
静止・腕上げ・手振り・交差・欠損復帰を同じ入力と設定で集計し、[比較結果](artifacts/comparison-results.md)に数値、再計算方法、限界と不採用理由を残した。
有効性を確認できなかったため、平滑化の既定値は維持する。

IKの極履歴は新観測時だけ確定し、描画予測では参照するよう修正した。時刻のない旧Pose入力は履歴へ確定しない。
観測間の描画回数を変える結合テストと旧経路の確定回数テストを追加した。
入力フィルターは実観測時刻、描画補間と角速度制限は描画時刻で進める。責務とコメントを同期し、独立確認は[評価](eval.md)に記録する。

共通の姿勢合成・IKの変更を含むため、依存する5タスクの実装・比較結果・状態を同じコミットにまとめる。
フロント全体のテストは677件成功・3件スキップ、型検査と本番ビルド、構造検査は成功した。

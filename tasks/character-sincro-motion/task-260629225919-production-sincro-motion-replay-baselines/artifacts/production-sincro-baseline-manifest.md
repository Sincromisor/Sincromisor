# Production Sincro Motion Replay Baseline Manifest

## Summary

This manifest reserves the production `simple-vrm` / `sincro` replay baseline set for
comparing later observe-only, dry-run, and applied motion pipeline changes.

The current implementation worktree has no browser camera access, no persisted
motion-debug recording from a real device, and no trusted production video fixture.
Therefore no fixture in this manifest is a captured production baseline. Every P0
fixture is recorded as `source: not-captured`; replay logs and metrics summaries
must not be treated as existing real-camera evidence.

## Baseline Scope

- Target page: `simple-vrm`
- Target mode: production `sincro`
- Retarget path: current production `poseSnapshot -> SincroPoseRetargeter -> direct bone write`
- Disabled paths: composer dry-run, new pipeline observe-only, final-pose playback comparison
- VRM: default production VRM at `sincromisor-frontend/public/characters/default.vrm`
  unless a later recapture explicitly records a scrubbed abstract avatar profile.
- Camera / video source: not captured in this task.
- Camera privacy rule: raw `deviceId`, `groupId`, and `label` are not stored.
  Future captures may store only scrubbed abstract settings such as width, height,
  frameRate, facing mode category, and permission state.

## Metrics Contract

Metrics summaries must use the current motion metrics facade:

- Summary generator: `calculateMotionMetricSummary`
- Baseline comparison: `compareMotionMetricSummaries`
- Summary schema: `sincro.motion-metrics.v1`
- Baseline schema: `sincro.motion-metric-baseline.v1`
- Threshold version: `initial-v1`

The task request uses human-readable baseline fixture ids for three motions that
currently have different `MOTION_P0_FIXTURE_IDS` values. Recapture artifacts should
preserve the requested id in this manifest and use the current metrics facade id in
the metrics JSON when those differ.

## Expected Artifact Layout

When a real production capture is available, save artifacts under this task
directory:

- Replay log: `artifacts/replay/<metrics-fixture-id>.ndjson`
- Optional compressed replay log: `artifacts/replay/<metrics-fixture-id>.ndjson.gz`
- Metrics summary: `artifacts/metrics/<metrics-fixture-id>.summary.json`
- Optional baseline wrapper: `artifacts/metrics/<metrics-fixture-id>.baseline.json`

No replay or metrics files were generated by this attempt.

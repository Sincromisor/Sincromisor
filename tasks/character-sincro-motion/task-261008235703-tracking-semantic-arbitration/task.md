# 追跡品質に応じて動作プリセットの腕上書きを制御する

## 背景・目的

現在は動作意図の信頼度が0.65以上なら、`semantic`層が追跡中の上腕・前腕・手を上書きできる。判定は観測された腕の品質を比較していない。指の補正も意図に応じて観測された曲げを制限する。認識が合っていても、実際の動きから定型姿勢へ吸い寄せる可能性がある。

`sincro`の「利用者の動きをまねる」という既存目的に合わせ、有効な観測を優先し、補助動作は情報が不足する部位へ限定する。

## 完了条件

- [x] 新鮮で高信頼の腕追跡がある部位は、意図認識だけを理由に定型姿勢で置き換えない。品質が低い部位や欠損時だけ、信頼度と経過時間に応じて補助姿勢を混ぜる。
- [x] 指も有効な観測曲げを優先し、意図からの補完は未観測・低信頼の指に限定する。左右を独立に判定する。
- [x] 補助姿勢への移行と追跡復帰の境界が連続し、古い意図や停止後の手姿勢が復活しない。意図の信頼度と追跡の信頼度を同じ意味の値として扱わない。
- [x] 最終姿勢の診断から、どの部位へ何を採用し、どの層を抑制したかが分かる。既存の`suppressedLayers`と理由コードを優先して利用する。
- [x] `chat`、AI発話中の口形優先、頭部の所有範囲を変えない。既存の意味動作・指切り戻しフラグの削除タスクとは分離する。

## 設計判断と変更対象

観測された動きの同期を標準にする。演出の強さを選ぶ新しい利用者設定は追加しない。このタスクは表示の優先順位を変更するため、[モーション設計](../../../documents/design/frontend/character/motion.md)の意味動作方針と診断を同期する。

- [補助層の接続](../../../sincromisor-frontend/src/character/runtime/sincroVrmPoseComposerSemanticFingerLayers.ts)、`semanticMotionPoseLayer.ts`
- [指の補正](../../../sincromisor-frontend/src/character/motionIntent/fingerCurlPoseLayer.ts)、必要最小限の層の入力型

## 確認方法

同一の高信頼追跡姿勢へ異なる意図を入れても腕の最終姿勢が変わらず、片腕だけの欠損ではその側だけ補完することを確認する。追跡品質が閾値付近を往復する系列で不連続がないことを確認する。既存録画の意図と追跡が両方ある区間で比較し、欠ける組み合わせは合成入力と明記する。

## 実装・確認結果

腕の追跡信頼度と観測年齢から左右別の保護重みを求め、不足する部位だけ補助姿勢を混ぜる。
意図の信頼度とは分離し、古い意図をPose時計で失効させる。指は有効な曲げ・開閉の観測を優先し、欠ける群だけ補う。
部分抑制も既存の診断理由へ残す。

同一観測に異なる意図、片腕欠損、閾値付近、保持期限、古い意図と停止後を本番合成で確認した。
[比較記録](artifacts/comparison-results.md)に、実写に競合例が足りず合成入力で確認した範囲を明記した。
既存の会話・口形・頭部の所有範囲と切り戻しフラグは維持し、モーション設計とコメントを同期した。

共通の姿勢合成・IKの変更を含むため、依存する5タスクの実装・比較結果・状態を同じコミットにまとめる。
フロント全体のテストは677件成功・3件スキップ、型検査と本番ビルド、構造検査は成功した。

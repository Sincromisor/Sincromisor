# 追跡と補助姿勢の確認

同一の高信頼追跡へ `tracking`・`pointing`・`peace`・`thumbsUp`・`wave` を与え、腕と観測済みの指の最終姿勢が一致することを固定入力で確認した。
片側だけ信頼度を落とすと、その側だけ補助姿勢を使う。追跡閾値0.65の前後と250msの新鮮さの境界で重みが連続する。
高信頼の追跡は250ms保護し、その後は既存の腕予測期限700msまで保護を弱める。
意図の有効期間は独立にPose時計で250msとし、Hand時計との原点差を減算しない。
指の未観測群を意図で補う場合も意図側の信頼度を掛け、観測済みの曲げを上書きしない。
部分抑制も `suppressedLayers` の `semantic_conflict` に残し、採用ボーンは既存の最終姿勢診断で確認できる。

既存6録画610フレームと、保存済みHand・Gestureを足した3区間を本番合成へ通した。
[集計](../../task-261008235703-canonical-torso-application/artifacts/comparison-summary.json)では、今回の区間の補助層抑制は0件だった。
意味動作のプリセットと高信頼追跡が競合する十分な実写例はなく、抑制規則の確認は上記の合成入力によるものと区別する。
手のボーンを所有している件数には中立姿勢の出力を含み、Hand検出成功件数ではない。

停止・リセット後と古い意図では補助姿勢を復活させないことを本番合成テストで確認した。
頭部・口形・会話モードの所有範囲と既存の切り戻しフラグは維持し、管理側を含む全体テストで回帰確認した。

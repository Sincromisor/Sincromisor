### 判断 / 実装方針

- Gesture は Hand snapshot に混ぜず、`features/gaze/gestureTracking/` の独立 snapshot / tracker として追加した。Hand tracker の左右 assignment を正本にし、GestureRecognizer handedness は mismatch warning の材料に限定した。
- Gesture Recognizer は `/3rd_party/gesture_recognizer.task` 固定、delegate は既存 Face / Hand と同じ Firefox CPU / その他 GPU policy とした。GPU unavailable / init failure / inference failure は lost snapshot + warning に落とし、Face / Pose / Hand runtime を止めない方針にした。
- `TrackerRuntimePoseOptions.gesture` は production `startSincroFaceTracking()` から Pose enabled 時だけ明示有効化する。実行条件は Pose enabled かつ Hand enabled、さらに同一 frame で Hand が走ったときに限定し、face-only / comfortable-idle / `roi-hand-paused` では lost snapshot または skip summary を publish する。
- observe-only pipeline では `SincroGestureMotionSnapshot` を直接 MotionIntent へ渡さず、`GestureIntentObservation` へ正規化して `MotionIntentEstimator.update({ gesture })` へ渡す。`ReliabilityMap.gesture` は `lost` / `neutral` / `no_observation` placeholder のまま維持した。
- Debug Console は Gesture full snapshot ではなく、availability、左右 top label、confidence、source、warnings、inferenceFps の compressed summary だけを持つ。
- ドキュメント同期は `documents/design/frontend/character/tracking.md` と `documents/design/frontend/character/motion.md` に反映した。公開 WebRTC / backend 契約、設定 UI、env、motion-debug recording schema の破壊的変更は行っていない。

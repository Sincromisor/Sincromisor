# 体幹と腕の座標原点・尺度を統一する

## 背景・目的

本番の正規化処理は腕の座標を肩中心、下半身を腰中心に変換する。`estimateCanonicalTorsoFrame()`は両者の`world.normalized*`を共通の原点とみなし、肩と腰の中心を差し引いている。起票時の本番正規化関数を通す固定入力で、有効な全点を与えても体幹が`mixed`、信頼度が0.45へ低下した。

さらに、体幹の横軸・縦軸が直交する保証がなく、腕の橋渡し処理は撮影者の肩幅で正規化した座標からVRMのメートル単位の肩位置を引く。相似なVRMを2倍の寸法にするだけで、同じ入力の手首方向が約12.51度変わることを再現した。過去の到達距離修正は長さを直したが、この方向の混在は残る。

## 完了条件

- [x] 肩・腰・肘・手首を同一原点・単位で体幹推定へ渡す。既存スナップショットの`world.rawX/Y/Z`などから共通座標を作り、異なる原点の`normalized*`を混ぜない。必要な元座標が無い旧記録は欠損を明示して既存の代替処理へ進める。
- [x] 体幹基底を直交・正規化し、左右と前方の向きを保つ。退化した肩線や腰欠損時は有効な履歴または中立へ戻し、根拠のない体幹回転を作らない。
- [x] 撮影者側の肩位置を撮影者側の座標内で引いて腕方向を作り、VRMの骨長を使う距離変換はその後に行う。手首と肘の曲がる方向の両方で原点・単位を揃える。
- [x] 撮影者の平行移動、一様拡大、相似VRMの一様拡大で、期待する無次元の腕方向と到達率が変わらない。左右の上げ下げ・前出し・交差について、鏡像とMediaPipe→VRMの符号を確認する。
- [x] `reach`の要求値・適用値・超過値は同じ腕長を分母にする既存契約を維持する。制限閾値を緩めて座標誤差を隠さない。

## 範囲と設計判断

共通表現と腕IK入力の幾何に絞る。正規化済みローカル姿勢への一括書き込み、二関節の解析的IK、関節制約は維持する。体幹回転を表示へ配分する変更は[後続タスク](../task-261008235703-canonical-torso-application/task.md)で扱う。

既存の保存フィールドの座標の意味を無言で変更しない。内部で導出する撮影者の肩相対方向を基本にし、保存型の追加が必要な場合は解析・複製・再生・テストを同期する。旧ログから再構成できない値を推測で埋めない。

## 確認方法

`normalizeSincroPoseLandmarkerResult()`から始める固定入力で体幹の有効性と座標不変条件を検証する。手作りの共通表現だけを通すテストで終えない。実写は提供済みの交差・腕上げ記録の`world.raw*`から再計算し、方向、肘反転、到達制限を現行版と比較する。保存済み610フレームで体幹がすべて`mixed`だったことも基準にするが、単に信頼度を上げる修正で済ませず、実際の座標と表示姿勢を確認する。

## 実装・確認結果

肩・腰・腕は生のワールド座標から共通の軸とメートル単位へ変換し、体幹基底を直交化した。
腕の保存座標は肩幅単位を保ち、IKへ渡す前に撮影者側の肩位置を引く。
元座標がない腕は信頼度0としてタプルを省略し、旧正規化座標で補わない。
体幹の新しい座標単位は任意の識別子で記録し、設計と読み取り契約を同期した。

本番正規化からの8テストで、平行移動・撮影者/VRMの一様拡大、左右・上下・前出し・交差、
肩線が傾いた場合の直交性、腰欠損時の基底全体の保持、旧記録の欠損を確認した。
既存6動作610フレームを固定入力で再計算し、体幹がすべて `mixed`から `pose`へ変わることと
到達制限・肘反転を比較した。詳細は[比較結果](../task-261008235701-recorded-motion-quality-baseline/artifacts/comparison-results.md)に記録した。
交差と両腕挙上を動画と並べて目視したが、実写に一致しない最終姿勢は残る。幾何の整合性と表示品質全体は区別する。

変更した本番の処理・型・時計境界のコメントを点検し、モーション設計と追跡設計を同期した。
体幹基底・腕信頼性・橋渡しの型は既存所有者から分離した。独立評価と全体確認は[評価記録](eval.md)を参照する。

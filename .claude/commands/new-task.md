---
description: 対話の文脈から実装可能な task.md を起票する（実装・完了処理はしない）
argument-hint: <タイトル / 起票したい内容の要約>
---

`$ARGUMENTS` を、直前までの対話と調査を知るこのセッションが起票する。

1. `npm run tasks:new -- <category> "<title>" [--slug=<slug>]` で雛形を作る。
2. `tasks/AUTHORING-CHECKLIST.md` を目安に、背景、検証可能な完了条件、変更範囲、既存コードとの整合、必要なテストと文書同期先を `task.md` に記す。局所変更に高リスク統合向けの表や不変条件を要求しない。
3. ユーザーが独立レビューを求めた場合、または複数の所有者・状態機械・外部境界をまたぐ高リスク変更の場合だけ `task-reviewer` を呼ぶ。結果は `review.md` と `meta.yaml` の `review` に記録する。
4. 作成したタスクのパスと要点を報告する。

起票だけではコミット、実装、評価、完了処理を行わない。

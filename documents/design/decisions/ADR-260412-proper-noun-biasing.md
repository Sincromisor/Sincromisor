# ADR-260412 固有名詞認識の補強方針

## 状態

- 採用済み

## 背景

SpeechRecognizerNemo は 1-best 結果をほぼそのまま返しており、固有名詞や既存語をもじった名称が一般語彙へ引っ張られやすかった。モデル追加学習は重く、個人開発で反復しにくい。

## 決定

- モデル追加学習ではなく、CSV 辞書を使う段階的補強を採用する。
- 初期段階は確定結果に対する読み一致補正を優先する。
- 曖昧語は強制置換せず、文脈による認識候補の補強と上位N候補の再順位付けを段階導入する。
- WebSocket 応答スキーマは初期段階では変更しない。

## 検討した選択肢

| 選択肢                        | 利点                       | 欠点                                |
| ----------------------------- | -------------------------- | ----------------------------------- |
| CSV 辞書 + 確定後処理         | 運用で語彙追加しやすい     | 過補正対策が必要                    |
| NeMo 文脈による認識候補の補強 | 復号器段階で補強できる     | 復号方針の制約確認が必要            |
| 上位N候補の再順位付け         | 曖昧語に強い               | N-best 取得と採点の実装コストがある |
| 追加学習                      | 根本的な精度向上が見込める | データと運用コストが大きい          |

## 影響

- 辞書仕様は `contracts/proper-noun-dictionary.md` を正本にする。
- 補強計画は `initiatives/proper-noun-biasing.md` に分離する。
- 未補正の音声認識結果と補正の追跡記録はデバッグ可能に残す。

## 見直し条件

- 辞書補正による過補正が多く、文脈ルールや再順位付けでも改善しない場合。
- 十分な学習データが揃い、追加学習の運用が現実的になった場合。

# フロントエンド VAD

## 要約

- フロント側VADではマイク入力のRMS / Peakと学習VADを使い、判定結果を送信ゲートやUI表示に利用する。
- VADはUIではなく音声 / メディア制御の一部として扱う。
- 診断値は診断Consoleの音声 / 状態から確認できるようにする。

## 対象範囲

- 対象
    - フロント側VADモード
    - VADパラメータ
    - 診断Console観測項目
- 非対象
    - サーバー側のSpeechExtractor
    - 音声認識モデル

## 責務

- `src/features/media/userMedia`
    - マイク / カメラストリーム、機器制約、トラック生存期間、音声プロファイルを置く。
- `src/features/media/vad`
    - Silero VAD処理担当、学習済みVADクライアント、音声処理実行時、発話状態を置く。
- `src/features/media/devices`
    - メディア機器リストサービスを置く。
- UserMedia / 音声処理
    - マイクストリームから音量の包絡線を計算する。
- VAD状態
    - 発話中 / 無音 / 不確実などの状態をアプリ制御へ渡す。
- UI
    - VAD状態を通常UIと診断Consoleへ表示する。

## モード

- RMS / Peak
    - 軽量で、即時反応が必要な表示に使う。
- 学習VAD
    - ノイズ耐性が必要な発話判定に使う。
- 厳格判定
    - 誤検出を抑えたい場面で使う。

## 変更時の確認

- VADパラメータを変更したら診断Consoleの表示と設定UIの文言を確認する。
- 音声機器切替時にVAD状態が古いストリームを参照していないか確認する。
- サーバー側のSpeechExtractorの仕様変更とは別文書で扱う。

## 音声折り返しによる確認

[RTCの起動手順](../../../../sincromisor-server/sincro-rtc/README.md)に従い、Consulと下流を使わずRTCを起動する。ブラウザーの「体験を選ぶ」で「入力音声を折り返す」を選び、ヘッドホンを使用して接続する。

1. 音声設定で「無音時の送信を抑える」を無効にし、入力音声が返ることを確認する。
2. 同じ設定を有効にし、診断ConsoleのVAD判定と返却音声を比較する。必要に応じて既存の手動閾値・学習VAD設定で発話と非発話を比較する。
3. 「マイクをミュートする」で送信を止め、解除後に音声が戻ることを確認する。停止・再接続も確認する。

VADの初期値は従来どおり無効である。マイク→フィルター→VADゲート→送信用トラックの順序は通常モードと共通で、診断時だけ迂回する経路は設けない。視線による自動ミュートはecho接続中には適用しない。

この診断で確認できるのはブラウザーの入力処理とRTCまでの音声往復である。サーバー側の区間抽出・認識・応答生成・合成は実行せず、認識文やモーラも生成しない。入力はRTCで復号・再サンプリング・再符号化されるため、元の音声ビット列の一致を確認する用途には使わない。

# 設定UIの項目一覧

## 要約

起動前ダイアログと開始後の基本設定に表示される入力、操作、状態表示を列挙する。値と制約の正本は[設定既定値](../../../../sincromisor-frontend/src/app/settings/sincroAppSettingsDefaults.ts)、表示の正本は[共通フィールド](../../../../sincromisor-frontend/src/features/settings/react/fields/)と[開始後画面](../../../../sincromisor-frontend/src/app/settings/react/sincroControlPanelPages.tsx)である。画面から操作できない内部設定は末尾で区別する。

## 一覧の読み方

「前後」は起動前と開始後の両方、「前のみ」「後のみ」は片方の画面を表す。真偽値は `true`がオン、`false`がオフである。既定値はページ側の利用可否判定や利用者が変更する前の値であり、実際の初期表示でオフや操作不可になる場合がある。

数値は「下限〜上限 / 刻み」で記載する。設定適用時に範囲内へ制限し、刻みに丸め、非有限値は下限へ戻す。保存値の復元では入力刻みへ丸め直さない。動作量のスライダーは任意刻みで復元値を表示し、操作時に設定モデルが0.01刻みへ正規化する。更新・購読の設計は[設定UIの設計](settings-design.md)を参照する。

## 体験

| 項目・設定キー        | 値・既定値                     | 表示・反映                                                                                        |
| --------------------- | ------------------------------ | ------------------------------------------------------------------------------------------------- |
| 体験を選ぶ `talkMode` | `chat` / `sincro`、既定 `chat` | 前後。「キャラクターと話す／キャラクターになる」と説明を表示。動作へ即時反映、RTCへ再接続時に反映 |

## キャラクター

| 項目・設定キー                          | 値・既定値                                     | 表示・反映                                         |
| --------------------------------------- | ---------------------------------------------- | -------------------------------------------------- |
| 3Dキャラクターを表示 `enableCharacter`  | 真偽値、`true`                                 | 前後。ページ・端末の利用可否に従う                 |
| 上半身モーション `characterMotionScale` | `0〜1.2 / 0.01`、`0.72`                        | 前後。表示が必要。呼吸・聞き姿勢・AI発話中の動作量 |
| VRMファイルを選択・ドロップ             | VRM 1.0ファイル                                | 前のみ。概要・詳細から同じ操作を使う               |
| 現在のVRM状態                           | 既定、保存モデル、選択ファイル名、拒否理由など | 前後。同じダイアログ所有者の状態を表示             |
| キャラクターを選び直す                  | 接続停止後に起動前設定を開く                   | 後のみ。実行中の即時交換は行わない                 |

VRMの状態と選択は[起動前VRM部品](../../../../sincromisor-frontend/src/features/dialog/react/components/dialogSettingsSections.tsx)と[VRM作業サービス](../../../../sincromisor-frontend/src/features/dialog/model/dialogVrmWorkflowService.ts)が所有する。通常設定のスナップショットにファイルは含めない。

## マイク・音声

| 項目・設定キー                                  | 値・既定値                                 | 表示・反映                                                                   |
| ----------------------------------------------- | ------------------------------------------ | ---------------------------------------------------------------------------- |
| マイク入力 `audioInputDeviceId`                 | 機器IDまたは `undefined`、既定 `undefined` | 前後。既定選択はブラウザー既定のマイク。実行中は入力再取得と送信トラック交換 |
| ノイズを抑える `enableNoiseSuppression`         | 真偽値、`true`                             | 前後。ノイズ抑制                                                             |
| 音の回り込みを抑える `enableEchoCancellation`   | 真偽値、`true`                             | 前後。エコー除去                                                             |
| 音量を自動で整える `enableAutoGainControl`      | 真偽値、`false`                            | 前後。自動利得調整                                                           |
| 無音時の送信を抑える `enableVadGate`            | 真偽値、`false`                            | 前後。方式の選択は開発者ツール                                               |
| にぎやかな場所向けに調整 `enableVenueNoiseMode` | 真偽値、`false`                            | 前後。フィルター・VAD閾値をまとめて適用                                      |
| 自動でミュートする `enableAutoMute`             | 真偽値、`false`                            | 前後。視線が必要。無効時はオフへ戻し操作不可理由を表示                       |

音声補正は実行時に反映を要求し、操作可否は `settingsUiState`に従う。適用結果は[開発者ツールの音声項目](debug-items.md#音声の表示と調整)で確認する。

## カメラ・動き

| 項目・設定キー                        | 値・既定値                                       | 表示・反映                                                         |
| ------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------ |
| 追跡用カメラ `videoInputDeviceId`     | 機器IDまたは `undefined`、既定 `undefined`       | 前後。既定選択はブラウザー既定のカメラ。追跡有効時は再取得         |
| 顔の向きを使う `enableCharacterGaze`  | 真偽値、`true`                                   | 前後。視線機能の利用可否と理由を表示                               |
| 姿勢を使う `enableSincroPoseTracking` | 真偽値、`true`                                   | 前後。表示・視線が必要                                             |
| 姿勢同期 `sincroPoseRetargetScale`    | `0〜1.2 / 0.01`、`0.68`                          | 前後。表示・視線・姿勢が必要                                       |
| 目線追跡 `characterEyeTrackingScale`  | `0〜1.2 / 0.01`、`0.68`                          | 前後。表示・視線が必要                                             |
| 初期調整のステップ・状態・案内        | 事前確認、正面姿勢、腕の姿勢、手を開く、顔の向き | 後のみ。較正状態が `active`のとき表示                              |
| 初期調整の再試行                      | 現在ステップを指定                               | 後のみ。記録のあるステップを再試行。完了後も明示操作なら再試行可能 |
| カメラ品質の改善案内                  | 状態から渡された案内文1件                        | 後のみ。案内があるときに表示                                       |

動作量3項目は保存値を丸めず百分率で表示する。較正の表示条件は[再試行カード](../../../../sincromisor-frontend/src/app/settings/react/components/initialCalibrationRetryCard.tsx)、カメラ品質の案内は[案内部品](../../../../sincromisor-frontend/src/app/settings/react/components/diagnosticsStatusCards.tsx)が扱う。

マイク・カメラそれぞれの分類と起動前概要に「機器一覧を更新」を置く。取得中は無効化し、完了・失敗を案内する。列挙未対応、取得エラー、候補なし、名称未解決、機器不在、選択名、利用不可理由は既存の機器フィールドから表示する。概要のカメラ選択は顔追跡が有効な場合だけ表示する。

## 画面・保存

| -------------------- | --------------------------------------------- | ---------------------------------------- |

## 接続と画面全体の操作

| 項目                       | 配置・条件                                                           |
| -------------------------- | -------------------------------------------------------------------- |
| 開始する                   | 起動前概要・詳細の固定領域。既存の開始条件と不許可理由を表示         |
| 詳しい設定／開始画面へ戻る | 起動前の2表示を切り替える。設定値は共有                              |
| トップへ戻る               | 起動前の固定領域から `/`へ移動                                       |
| 接続状態・詳細・反映案内   | 常設設定の固定領域。接続済み・準備中・接続中・要確認・停止中・未接続 |
| 会話を開始／接続を停止     | 常設設定の固定領域。有効なアプリ制御がある場合に操作可能             |
| 分類の切り替え             | 体験、キャラクター、マイク・音声、カメラ・動き、画面・保存           |
| 基本設定を開く・閉じる     | 右上メニューと外枠。開発者ツールと排他表示                           |

ICE・Signaling、顔座標・注視、VAD状態・確率は既存の開発者ツールで参照する。「姿勢を強制継続」も開発者ツールの `Sincro`へ移し、通常設定には表示しない。詳細は[デバッグ項目](debug-items.md)を参照する。

## Looking Glass専用設定

`looking-glass-vrm`の開始後設定のみ。共通5分類の後に追加し、体験やタイトルは共通分類に残す。すべて次のLooking Glass開始で描画へ適用する。

| 画面上の項目・設定キー      | 範囲 / 刻み     | 既定値 |
| --------------------------- | --------------- | ------ |
| タイルの高さ `lgTileHeight` | `256〜2048 / 1` | `512`  |
| 視差ビュー数 `lgNumViews`   | `8〜64 / 1`     | `45`   |
| 奥行きの強調 `lgDepthiness` | `0〜4 / 0.05`   | `0.85` |
| 縦方向の視野角 `lgFovyDeg`  | `5〜80 / 0.5`度 | `24`   |
| 注視する高さ `lgTargetY`    | `-2〜4 / 0.05`  | `0.85` |
| 注視する奥行き `lgTargetZ`  | `-1〜2 / 0.05`  | `0.2`  |
| 注視する範囲 `lgTargetDiam` | `0.1〜3 / 0.05` | `1.5`  |

プリセットは次の7値を一括適用する。並びはタイルの高さ、ビュー数、注視する高さ、注視する奥行き、注視する範囲、奥行きの強調、縦方向の視野角である。定義元は[Looking Glass設定部品](../../../../sincromisor-frontend/src/app/settings/react/components/lookingGlassSettingsSection.tsx)。

| プリセット | 適用値                                |
| ---------- | ------------------------------------- |
| 標準       | 上表の既定値へ戻す                    |
| 縦長       | `640, 45, 1.35, 0.45, 0.8, 0.9, 22`   |
| 広角       | `512, 48, 1.15, 0.6, 0.95, 1.2, 30`   |
| 焦点調整用 | `512, 45, 0.95, 0.05, 1.25, 0.85, 24` |

| 操作・表示        | 内容・条件                                                                                       |
| ----------------- | ------------------------------------------------------------------------------------------------ |
| 表示状態          | 状態、任意のコード・詳細。`active`は正常、`error`は警告として表示                                |
| 反映タイミング    | 「停止・再開始が必要」「次回起動で反映」「変更の反映待ちなし」。再開始または次回開始の案内を併記 |
| Looking Glass開始 | `starting` / `active`以外で操作可能                                                              |
| Looking Glass停止 | `starting` / `active`で操作可能                                                                  |
| 焦点調整の案内    | ぼける場合に注視する奥行きと注視する範囲を少しずつ調整する案内                                   |

## 現行画面に出ない設定

| 設定キー          | 値・既定値      | 現在の扱い                                                                                           |
| ----------------- | --------------- | ---------------------------------------------------------------------------------------------------- |
| `enableTalk`      | 真偽値、`true`  | 内部の開始時設定。一般設定の入力はない                                                               |
| `enableInspector` | 真偽値、`false` | 内部の開始時設定。診断コンソールを開く操作とは別で、一般設定の入力はない                             |
| `enableVR`        | 真偽値、`false` | 共通部品には「VRで開く準備をする」があるが、現行の初期化処理は対応可否を `false`とするため表示しない |

これらの開始時設定を接続済みの機能として案内しない。定義元と表示条件は[設定UIの設計](settings-design.md#反映タイミングと利用条件)を参照する。

## 保存範囲

共通5分類とLooking Glassの設定入力をページ別に保存する。状態表示、分類、タブ、非表示の開始時設定は保存しない。形式、URL優先、機器IDを既定に戻す操作と失敗時の扱いは[保存と復元](settings-design.md#保存と復元)を参照する。

## 全設定の初期化

起動前の詳細・開始後の「画面・保存」にある「全て初期設定に戻す」で、全対象ページの通常設定・デバッグ調整、保存VRM本体とサムネイルを削除して再読込する。削除範囲、取消・失敗時の扱いは[全設定の初期化](settings-design.md#全設定の初期化)を参照する。

## 項目に添える説明

体験、顔・姿勢の追跡、動作量、音声補正は入力の近くへ用途を常時表示する。追跡用カメラは顔の向き・視線・姿勢に使用する。操作不可の理由、機器不在、体験の再接続、Looking Glassの再開始は対象項目の近くで案内する。入力の関連付けと共通の外観は[説明と状態の表示](settings-design.md#説明と状態の表示)に従う。

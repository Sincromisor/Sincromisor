# 設定UIの項目一覧

## 要約

起動前ダイアログと開始後の基本設定に表示される入力、操作、状態表示を列挙する。値と制約の正本は[設定既定値](../../../../sincromisor-frontend/src/app/settings/sincroAppSettingsDefaults.ts)、表示の正本は[共通フィールド](../../../../sincromisor-frontend/src/features/settings/react/fields/)と[開始後画面](../../../../sincromisor-frontend/src/pages/simpleVrm/react/simpleVrmControlPanelPages.tsx)である。画面から操作できない内部設定は末尾で区別する。

## 一覧の読み方

「前後」は起動前と開始後の両方、「前のみ」「後のみ」は片方の画面を表す。真偽値は `true` がオン、`false` がオフである。既定値はページ側の利用可否判定や利用者の変更が入る前の値であり、実際の初期表示でオフや操作不可になる場合がある。

数値は「下限〜上限 / 刻み」で記載する。設定適用時に範囲内へ制限し、刻みに丸め、非有限値は下限へ戻す。宣言上の既定値には刻みの倍数でない値もあるため、既定値と入力後の正規化を区別する。更新・購読の設計は[設定UIの設計](settings-design.md)を参照する。

## 会話

| 画面上の項目・設定キー  | 値・既定値                                       | 表示・反映                                                                         |
| ----------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------- |
| タイトル `titleText`    | 文字列。既定 `Sincromisor`。空文字列は既定へ補正 | 前後。Looking Glass専用の開始後画面では非表示。表示へ反映                          |
| トークモード `talkMode` | `chat` / `sincro`。既定 `chat`                   | 前後。Looking Glassでも表示。キャラクター動作へ反映し、RTCのモードは再接続時に反映 |

## デバイス

| 画面上の項目・設定キー            | 値・既定値                                                                                                                                                  | 表示・反映                                                                                       |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| マイク入力 `audioInputDeviceId`   | 列挙された音声入力の機器ID、または `undefined`。既定 `undefined`                                                                                            | 前後。空の選択肢は「ブラウザ既定のマイクを使う」。実行中は入力再取得と送信トラック差し替え       |
| 視線用カメラ `videoInputDeviceId` | 列挙された映像入力の機器ID、または `undefined`。既定 `undefined`                                                                                            | 前後。空の選択肢は「ブラウザ既定のカメラを使う」。追跡有効時はカメラ再取得                       |
| デバイス一覧の再読み込み          | 操作。設定値なし                                                                                                                                            | 前後。ボタンは「再読み込み」/「更新中...」。取得中は操作不可。完了・失敗の結果文も表示           |
| 機器選択の案内                    | 列挙未対応、取得エラー、候補なし、権限による名称未解決、選択機器不在、選択中の名称、利用不可理由                                                            | 前後。該当する案内を表示                                                                         |
| 調整ステップ・状態・案内          | `precheck`（事前確認）、`neutral`（正面姿勢）、`a_pose`（腕の姿勢）、`hand_open`（手を開く）、`face_yaw_optional`（顔の向き）。セッション状態と先頭の案内文 | 後のみ。初期調整コントローラーが `active` のとき表示                                             |
| 再試行                            | 現在の調整ステップを指定する操作                                                                                                                            | 後のみ。現在ステップの記録があると表示。`ready` / `ready_without_hands` でも明示的に再試行できる |

初期調整の表示条件は[再試行カード](../../../../sincromisor-frontend/src/pages/simpleVrm/react/components/initialCalibrationRetryCard.tsx)に従う。選択済み機器の不在などによる開始制限は[設定UIの設計](settings-design.md#失敗時の案内)を参照する。

## 音声

すべて前後に表示する真偽値で、実行時に反映を要求する。各入力は対応する `settingsUiState` が操作不可なら無効になる。

| 画面上の項目・設定キー                          | 既定値  | 用途・反映先                                                      |
| ----------------------------------------------- | ------- | ----------------------------------------------------------------- |
| ノイズを抑える `enableNoiseSuppression`         | `true`  | マイク入力のノイズ抑制                                            |
| 音の回り込みを抑える `enableEchoCancellation`   | `true`  | マイク入力のエコー除去                                            |
| 音量を自動で整える `enableAutoGainControl`      | `false` | マイク入力の自動利得調整                                          |
| 無音時の送信を抑える `enableVadGate`            | `false` | ローカルVADによる送信抑制。検出方式の選択はデバッグUIで行う       |
| にぎやかな場所向けに調整 `enableVenueNoiseMode` | `false` | 会場向けのフィルター・VAD閾値をまとめて適用し、デバッグUIにも同期 |

音声補正3項目の適用結果と会場向け調整による具体的な変更値は[デバッグUIの音声項目](debug-items.md#音声の表示と調整)を参照する。

## 表示

以下はすべて前後に表示し、実行時の表示・追跡・動作に反映する。

| 画面上の項目・設定キー                        | 値・既定値              | 操作条件・用途                                                                           |
| --------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------- |
| 3Dキャラクターを表示 `enableCharacter`        | 真偽値、`true`          | ページ・端末側の利用可否に従う                                                           |
| 顔の向きを使う `enableCharacterGaze`          | 真偽値、`true`          | 視線機能の利用可否に従う。カメラで顔・視線を追跡                                         |
| sincroで姿勢を使う `enableSincroPoseTracking` | 真偽値、`true`          | キャラクター表示と視線がオンの場合に操作可能                                             |
| 姿勢を強制継続 `forceSincroPoseTracking`      | 真偽値、`false`         | 対応する操作可否に加え、表示・視線・姿勢がオンの場合に操作可能。低性能端末向けの診断用途 |
| 自動でミュートする `enableAutoMute`           | 真偽値、`false`         | 視線が必要。視線無効時はオフへ戻る                                                       |
| 上半身モーション `characterMotionScale`       | `0〜1.2 / 0.05`、`0.72` | キャラクター表示が必要。呼吸・聞き姿勢・AI発話中の動作量                                 |
| 姿勢同期 `sincroPoseRetargetScale`            | `0〜1.2 / 0.05`、`0.68` | 表示・視線・姿勢が必要。姿勢をモデルへ反映する強さ                                       |
| 目線追跡 `characterEyeTrackingScale`          | `0〜1.2 / 0.05`、`0.68` | 表示・視線が必要。眼球追跡の強さ                                                         |

動作量3項目は画面上で百分率を表示する。キャラクター表示、顔の向き、自動ミュートには利用不可理由の補足表示がある。

| VRM関連項目        | 値・操作                                                                          | 表示条件                                    |
| ------------------ | --------------------------------------------------------------------------------- | ------------------------------------------- |
| VRMファイルを選択  | 利用者のローカルVRMファイルを選択する                                             | 前のみ。「VRM-1.0 モデル」欄                |
| ドラッグ＆ドロップ | VRMファイルを渡す。ドラッグ中はドロップ先の案内を切り替える                       | 前のみ                                      |
| VRM状態            | 既定モデル使用中、前回選択モデル使用中、選択ファイル名、VRM以外の拒否などの状態文 | 前のみ。初期値は「既定のVRMモデルを使用中」 |

VRMの入力・状態は[起動前VRM部品](../../../../sincromisor-frontend/src/features/dialog/react/components/dialogSettingsSections.tsx)と[VRM作業サービス](../../../../sincromisor-frontend/src/features/dialog/model/dialogVrmWorkflowService.ts)が所有し、通常の設定スナップショットへファイルを含めない。

## 接続と画面全体の操作

| 項目                                | 表示・値                                                   | 操作条件・意味                                                                                                     |
| ----------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 接続状態と詳細                      | 前後。接続済み、開始準備中、接続中、要確認、停止中、未接続 | `connected`、`starting`、`connecting`、`degraded`、`stopping`、`stopped` / `idle` を表示文へ変換。詳細があれば併記 |
| 開始時設定の反映案内                | 前後。変更したキー、停止後の再開始、次回開始で反映する旨   | 開始時適用値との差分がある場合                                                                                     |
| カメラ環境の改善案内                | 後のみ。状態から渡された案内文を1件表示                    | 案内文がある場合                                                                                                   |
| VAD                                 | 後のみ。`unknown` / `speech` / `silence`                   | 状態表示                                                                                                           |
| Gaze                                | 後のみ。`-` / 注視 / 外れ                                  | 状態表示                                                                                                           |
| 顔X、顔Y                            | 後のみ。顔位置の数値、未取得時 `-`                         | 状態表示                                                                                                           |
| ICE、Signaling状態                  | 後のみ。通信側の状態文字列                                 | 状態表示                                                                                                           |
| 学習VAD、L-VAD確率                  | 後のみ。学習VADの状態、確率、未取得時 `-`                  | 状態表示                                                                                                           |
| Looking Glass状態、LGコード、LG詳細 | 後のみ。状態文字列、コード、詳細、未取得時 `-`             | 状態表示                                                                                                           |
| 会話を開始、接続を停止              | 後のみ                                                     | 有効なアプリ制御があると操作可能                                                                                   |
| 開始する                            | 前のみ。開始条件により文言と可否を変更                     | 有効なアプリ制御と開始条件が必要。不許可理由も表示                                                                 |
| トップへ戻る                        | 前のみ。`/` へのリンク                                     | 起動前ダイアログの下部                                                                                             |
| 分類の切り替え                      | 前後。通常は会話、デバイス、音声、表示、接続               | 設定値ではなく表示中の分類を切り替える                                                                             |
| 基本設定を開く・閉じる              | 右上メニュー、右側外枠の閉じるボタン、外側クリック         | 開発者ツールと排他表示。詳細は[共通規則](debug-design.md#右側ツールの共通規則)                                     |

状態カードの列挙元は[DiagnosticsStatusCards](../../../../sincromisor-frontend/src/pages/simpleVrm/react/components/diagnosticsStatusCards.tsx)である。これは基本設定内の状態表示であり、診断コンソールの同名項目とは配置を区別する。

## Looking Glass専用設定

`looking-glass-vrm` の開始後設定のみ。「会話」の代わりに先頭へ表示し、トークモードもここへ置く。すべて次のLooking Glass開始で描画へ適用する。

| 画面上の項目・設定キー    | 範囲 / 刻み      | 既定値 |
| ------------------------- | ---------------- | ------ |
| タイル高さ `lgTileHeight` | `256〜2048 / 1`  | `512`  |
| 視差ビュー数 `lgNumViews` | `8〜64 / 1`      | `45`   |
| 奥行き強調 `lgDepthiness` | `0〜4 / 0.05`    | `0.85` |
| 縦FOV `lgFovyDeg`         | `5〜80 / 0.5` 度 | `24`   |
| 注視高さ `lgTargetY`      | `-2〜4 / 0.05`   | `0.85` |
| 注視奥行き `lgTargetZ`    | `-1〜2 / 0.05`   | `0.2`  |
| 注視範囲 `lgTargetDiam`   | `0.1〜3 / 0.05`  | `1.5`  |

プリセットは次の7値を一括適用する。並びはタイル高さ、ビュー数、注視高さ、注視奥行き、注視範囲、奥行き強調、縦FOVである。定義元は[Looking Glass設定部品](../../../../sincromisor-frontend/src/pages/simpleVrm/react/components/lookingGlassSettingsSection.tsx)。

| プリセット           | 適用値                                |
| -------------------- | ------------------------------------- |
| 標準 (`Default`)     | 上表の既定値へ戻す                    |
| 縦長 (`Portrait`)    | `640, 45, 1.35, 0.45, 0.8, 0.9, 22`   |
| 広角 (`Wide`)        | `512, 48, 1.15, 0.6, 0.95, 1.2, 30`   |
| 焦点調整用 (`Focus`) | `512, 45, 0.95, 0.05, 1.25, 0.85, 24` |

| 操作・表示        | 内容・条件                                                                             |
| ----------------- | -------------------------------------------------------------------------------------- |
| 表示状態          | 状態、任意のコード・詳細。`active` は正常、`error` は警告として表示                    |
| 反映タイミング    | 「停止後に反映」「次回起動で反映」「最新状態」。再開始の案内、または変更したキーを併記 |
| Looking Glass開始 | `starting` / `active` 以外で操作可能                                                   |
| Looking Glass停止 | `starting` / `active` で操作可能                                                       |
| 焦点調整の案内    | ぼける場合に注視奥行きと注視範囲を少しずつ調整する案内                                 |

## 現行画面に出ない設定

| 設定キー          | 値・既定値      | 現在の扱い                                                                                          |
| ----------------- | --------------- | --------------------------------------------------------------------------------------------------- |
| `enableTalk`      | 真偽値、`true`  | 内部の開始時設定。一般設定の入力はない                                                              |
| `enableInspector` | 真偽値、`false` | 内部の開始時設定。診断コンソールを開く操作とは別で、一般設定の入力はない                            |
| `enableVR`        | 真偽値、`false` | 共通部品には「VRで開く準備をする」があるが、現行初期化処理は対応可否を `false` とするため表示しない |

これらの開始時設定を接続済みの機能として案内しない。定義元と表示条件は[設定UIの設計](settings-design.md#反映タイミングと利用条件)を参照する。

## 保存範囲

会話・デバイス・音声・表示とLooking Glassの設定入力をページ別に保存する。状態表示、分類、タブ、非表示の開始時設定は保存しない。形式、URL優先、機器IDの既定復帰と失敗時の扱いは[保存と復元](settings-design.md#保存と復元)を参照する。

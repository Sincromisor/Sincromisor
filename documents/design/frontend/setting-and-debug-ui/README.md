# 設定UIとデバッグUI

## 要約

設定UIは会話・機器・表示を調整する利用者向け画面、デバッグUIは音声・追跡・通信を観測・調整する開発者向け画面である。起動前ダイアログと開始後の基本設定は共通の設定状態を使い、基本設定と開発者ツールは右側領域で排他表示する。

## 対象範囲

起動前ダイアログ、開始後設定パネル、Looking Glass専用設定、右側ツールメニューと外枠、診断コンソールを対象にする。項目一覧は現在のReact画面と呼び出し元を基準にし、型や部品だけが存在して画面に出ない設定は区別する。

通信データの定義は[フロントとのRTC契約](../../contracts/frontend-rtc.md)、キャラクターの動作処理は[キャラクター概要](../character/overview.md)、ページごとの構成は[ページ構成](../pages.md)を参照する。

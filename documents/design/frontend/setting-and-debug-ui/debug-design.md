# デバッグUIの設計

## 要約

- 開発者ツールの診断コンソールは音声・視線・姿勢・通信のスナップショットを7タブで表示する。
- Reactは診断状態を購読し、調整操作をモデルの窓口へ渡す。WebRTC、MediaPipe、音声入力そのものの制御は各実行時処理へ委譲する。
- 基本設定と開発者ツールは同じ右側外枠を使って排他表示する。
- 全表示項目と調整値は[デバッグUIの項目一覧](debug-items.md)を参照する。

## 対象範囲

右上ツールメニュー、右側外枠、診断コンソールの表示と調整を扱う。通常設定は[設定UIの設計](settings-design.md)、通信データは[RTC契約](../../contracts/frontend-rtc.md)、姿勢変換のアルゴリズムは[キャラクター設計](../character/overview.md)で扱う。

## 右側ツールの共通規則

| 所有者                                                                                            | 状態・責務                                                                       |
| ------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `SincroAppRightToolPanelService`                                                                  | メニューの開閉、選択中パネル `none` / `settings` / `debug`、状態購読             |
| [RightToolMenu](../../../../sincromisor-frontend/src/features/debug/react/rightToolMenu.tsx)      | 歯車ボタン、基本設定・開発者ツールの選択、メニュー外側クリック、ショートカット   |
| [RightToolFrame](../../../../sincromisor-frontend/src/app/shell/react/overlay/rightToolFrame.tsx) | 固定位置、画面幅に応じた幅、重なり順、スクロール、閉じるボタン、外側クリック閉じ |
| `SettingsShell` / `DebugConsole`                                                                  | 外枠内部の情報構成と表示                                                         |

Reactはアプリ制御の `debug` 操作窓口を使い、窓口の組み立て時に状態取得や購読登録を実行しない。設定と診断コンソールを同時に大きく重ねない。

`Ctrl+Alt+D` は診断コンソールの開閉に使う。メニューには現在の選択を示す状態があり、同じ項目を選ぶとそのパネルを閉じる。外枠を閉じる操作とRTC接続を停止する操作は別である。

## 診断コンソールの構成

| タブ表示名 | 内容                                                                     |
| ---------- | ------------------------------------------------------------------------ |
| `Status`   | 通信、入出力音量、VAD、顔・姿勢・視線、DataChannelの要約                 |
| `Audio`    | 入出力メーター、VADとモデル状態、音声補正の適用結果、フィルター・VAD調整 |
| `Messages` | `text_ch`、`telop_ch`、RTCイベントのログ                                 |
| `Gaze`     | カメラ映像・目標マーカー、顔位置・注視状態、対象選択と平滑化の調整       |
| `Sincro`   | 顔・姿勢・手の観測要約、姿勢変換とIKの状態・調整                         |
| `RTC`      | 接続状態、候補、エンドポイント、音声通信統計と推移グラフ                 |
| `SDP`      | OfferとAnswerのSDP                                                       |

`DebugConsole` は初期タブを `status` とし、タブ選択をReactのローカル状態に持つ。各パネルは取り付けたまま `hidden` で表示を切り替える。受信音声用の `rtcAudio` と視線プレビュー用の動画・目標マーカーもこの構造に含まれる。

## データと操作の流れ

| 実装                                                                                                      | 責務                                                           |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| [DebugConsoleManager](../../../../sincromisor-frontend/src/features/debug/model/debugConsoleManager.ts)   | 診断の共有スナップショット、イベント購読、設定・停止操作の窓口 |
| [スナップショット定義](../../../../sincromisor-frontend/src/features/debug/model/debugConsoleSnapshot.ts) | `audio`、`gaze`、`sincroMotion`、`rtc` の型と初期状態          |
| `debugConsoleAudioControls`                                                                               | 音声メーター、音声調整・VADのコールバック、補正の適用状態      |
| `debugConsoleGazeControls`                                                                                | 顔位置・注視状態・視線調整の更新                               |
| `debugConsoleSincroMotionControls`                                                                        | 顔・姿勢・手などの観測要約と姿勢変換設定の更新                 |
| `debugConsoleRtcControls`                                                                                 | RTC状態、ログ、統計、グラフ系列の更新                          |
| [DebugConsole](../../../../sincromisor-frontend/src/features/debug/react/debugConsole.tsx)                | `useSyncExternalStore` による購読とパネル選択                  |
| [各パネル](../../../../sincromisor-frontend/src/features/debug/react/panels/)                             | 診断表示、入力、モデルの適用窓口の呼び出し                     |

実行時処理はモデルの更新窓口へ観測結果を渡す。モデルは更新後のスナップショットを公開し、Reactが購読する。RTC・メディア・キャラクター実行時からReactデバッグ部品へ直接依存しない。

利用者の調整は `applyLocal…`、`applyCharacterGazeTrackingTuning`、`applySincroPoseRetargetConfig` などの窓口を経由する。モデルの値更新と登録済みコールバックにより実行時処理へ反映する。コールバック未接続時に表示値が変わっても、実行時適用の成功を意味しない。

音声補正のオン・オフは一般設定が持ち、診断側は適用結果を表示する。会場向け設定を変更するとフィルターとVAD閾値も変わるため、実行時の値を診断側へ同期する。無関係な一般設定の変更で診断側の調整を上書きしないよう、音声側は差分を適用する。

## 音声調整の保存

通常設定と同じページ別JSONの `audio` に、利用者が変更したフィルター・VAD方式・手動RMS閾値・学習VADプリセットと数値・厳格判定を保存する。数値調整には連続判定フレーム数を含み、会場プリセット解除後の状態再現に必要なピーク閾値も保存する。自動VADで変動する計測閾値、音量、検出結果、統計、初期同期は保存しない。

通常設定復元後・音声取得前に、接続済みの診断コールバックへプリセット、手動調整、VAD方式の順で渡す。音声処理が正規化した学習VAD値は表示と保存にも戻す。保存値をUIの刻みで丸めず、高精度プリセットの `0.00055` などを保つ。

個別フィルター・RMS調整による会場プリセット解除は通常設定にも保存する。会場プリセットを改めてオン・オフにした場合は、そのプリセットが所有する保存フィルター・RMS・ピーク閾値を解除し、次回も新しい選択を優先する。学習VADの独立した調整は保持する。不正値と保存失敗、全設定初期化は[設定の保存と復元](settings-design.md#保存と復元)に従う。

## 観測の粒度と制限

顔の表情係数はUIが選んだ7項目を表示する。姿勢の観測段階は利用可否、時刻、警告を要約し、合成処理は警告、抑制された層、制限されたボーン、全面適用の状態を表示する。

手は利用可否、追跡・検出、左右の由来、関心領域の警告、開き具合、信頼度、時刻を表示する。Reactへ未加工のランドマークや切り抜きオブジェクトを渡さず、必要な要約に留める。

姿勢変換の合成処理を切り戻す入力は `composerSemanticFingerApplicationMode` だけである。`off` は意味に基づく動作と指の層を切り分ける開発者向け操作で、通常設定や保存設定へ広げない。腕、体幹・肩、正規化済み姿勢の全面適用に対する旧段階別操作はなく、利用不可フレームから旧直接書き込み処理を起動しない。

未取得の数値や未実施の観測は `-`、`not measured`、状態コードなどで表す。初期スナップショットのゼロや既定値を測定結果と解釈しない。入力範囲・グラフの表示上限は、実行時の安全制限や性能保証とは区別する。

## 変更時の確認

- 診断項目を追加するときは、スナップショット提供元、表示パネル、整形処理を同時に確認し、[項目一覧](debug-items.md)を更新する。
- 調整操作は範囲・単位・既定値・無効条件と実行時のコールバックを照合する。一般設定と重なる値は反映方向も確認する。
- メニューや外枠変更は `RightToolFrame` と `overlay.css` を優先し、設定側へ重複した装飾を持たせない。
- 文書変更は変更MarkdownのPrettier確認と相対リンク確認を行う。画面操作やブラウザー検証を行う場合は[ブラウザー確認手順](../../../../.agents/skills/playwright-cli/SKILL.md)に従う。

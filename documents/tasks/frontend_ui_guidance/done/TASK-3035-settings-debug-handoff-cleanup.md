# TASK-3035 設定パネルと診断導線の重複整理

- 作成日: 2026-05-01
- ステータス: Done
- 優先度: High
- 親タスク: `TASK-3033`
- 依存: `TASK-3034`

## 目的

設定パネル内の `開発者向け` カテゴリと右上メニューの `開発者向け診断` が二重導線に見える問題を解消し、一般設定から診断へ移る場合も「同じ右側ツール領域の切替」として自然に見えるようにする。

## 背景

- `frontend_ui.md` では、設定パネルは一般ユーザー向け、Debug Console は開発者向け診断として役割分離する方針になっている。
- 現状は設定パネル左ナビ内にも `開発者向け` があり、一般カテゴリと同じ重さで並んで見える。
- 接続や音声のトラブル時に診断へ移る導線は必要だが、通常設定と診断項目を混ぜると情報密度の差が曖昧になる。

## スコープ

- `SimpleVrmControlPanel` のカテゴリ構成
- 設定パネル内から Debug Console へ移る handoff CTA
- 文言の整理

## 非対象

- Debug Console の診断項目追加
- 接続状態の判定ロジック変更
- 右上メニュー自体の popover redesign

## 実装タスク

1. 設定パネルの左カテゴリから `開発者向け` を外すか、一般カテゴリと同じ重さに見えない導線へ変更する。
2. `接続` ページ末尾、または設定パネルの説明文末に `詳しい診断を開く` の軽い handoff CTA を置く。
3. handoff CTA は `showRightToolDebugPanel()` を使い、同じ右側ツール領域の内容が切り替わる挙動にする。
4. CTA 文言は、通常利用者を脅かさず、必要時だけ診断へ進める表現にする。
5. 設定パネルの badge / title / description が `一般ユーザー向け設定` として一貫するよう調整する。

## 完了条件

- 設定パネル内で `開発者向け` が一般カテゴリと同じ重さで表示されない。
- 設定から診断へ移る導線が、右側ツール領域の切替として自然に動作する。
- 右上メニューの `診断` と設定内 CTA の役割が競合しない。
- 起動前 dialog のカテゴリ構成には不要な影響が出ていない。

## 確認

- `simple-vrm` で設定パネルを開き、左カテゴリと `接続` ページの導線を確認する。
- 設定パネルから Debug Console へ切り替え、panel が重ならないことを確認する。

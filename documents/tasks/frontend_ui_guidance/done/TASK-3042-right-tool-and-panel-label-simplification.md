# TASK-3042 右上ツールとパネル外枠の文言整理

- 作成日: 2026-05-07
- ステータス: Done
- 優先度: High
- 親タスク: `TASK-3041`
- 依存: なし

## 目的

右上ツールボタン、右上ツールメニュー、右側パネル外枠、Debug Console の重複見出しを整理し、`基本設定` と `開発者ツール` の2系統として明確に見える状態にする。

## 背景

- 右上ボタンに `ツール` と現在状態が表示され、スクリーンショット上でも視覚的に重い。
- メニュー項目に `設定` / `開発者向け診断` と説明文、さらに `表示中` / `開く` が並び、情報量が多すぎる。
- パネル外枠、メニュー項目、Debug Console 内部に `開発者向け診断` 相当の見出しが重複している。
- レビュー方針では `開発者ツール` にまとめ、設定側は `基本設定` に寄せる。

## スコープ

- `RightToolMenu`
- `RightToolFrame` の呼び出し側 title / ariaLabel
- `DebugConsole` のヘッダー文言
- 右上ツール関連CSSの見た目調整

## 非対象

- Debug Console の診断項目そのもの
- 接続通知文言
- SettingsShell 内部構造の大幅変更

## 実装タスク

1. 右上ツールボタンの可視テキスト `ツール` と現在状態表示を削除または最小化し、アイコン主体のボタンへ寄せる。
2. 右上メニューの設定項目名を `基本設定` にする。
3. 右上メニューとパネル外枠の診断系名称を `開発者ツール` に統一する。
4. メニュー項目の説明文 `会話・表示・接続の調整` / `RTC・音声・状態の確認` を削除する。
5. `表示中` / `開く` の状態ラベルを削除し、選択状態はスタイルで表現する。
6. Debug Console 内部の重複アイブロウを削除し、必要な見出しは `開発者ツール` に統一する。
7. `高度な調整 (Gaze Tuning)` は `高度な調整` に寄せる。
8. ARIA ラベルは見た目から消しても操作内容が分かるよう維持・更新する。

## 実装対象候補

- `sincromisor-frontend/src/react/debug/RightToolMenu.tsx`
- `sincromisor-frontend/src/react/debug/DebugConsole.tsx`
- `sincromisor-frontend/src/react/app-shell/SincroPageAppShell.tsx`
- `sincromisor-frontend/src/styles/sincroDebugConsole.css`

## 完了条件

- 右上ツールボタンがアイコン主体になり、冗長な `ツール` / `設定` 表示が出ない。
- メニュー内は `基本設定` と `開発者ツール` の2項目として読める。
- 選択状態はテキストではなく視覚状態で分かる。
- Debug Console 内に `開発者向け診断` / `Debug Console` / `開発者ツール` が重複して出ない。
- desktop / mobile で右上ボタンとメニューのサイズが不自然に崩れない。

## 確認観点

- `simple-vrm` の右上ボタンがヘッダー内で過度に目立たない。
- メニューを開いた時に、説明文なしでも2項目の意味が分かる。
- パネルを切り替えた時に、現在表示中のパネルが視覚的に分かる。

## 完了メモ

- 右上ボタンはアイコン主体に整理済み。
- 右上メニューは `基本設定` / `開発者ツール` の2項目に整理済み。
- 選択状態は `is-active` の視覚スタイルで表現する。
